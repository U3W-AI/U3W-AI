## 一、项目结构

```
WxFbsir/
├── WxFbsir-admin/          # 后台管理服务（主节点）
├── WxFbsir-business/       # 业务模块
├── WxFbsir-common/         # 通用工具模块
├── WxFbsir-engine/         # 引擎节点服务（副节点）
├── WxFbsir-framework/      # 框架核心模块
├── WxFbsir-generator/      # 代码生成模块
├── WxFbsir-quartz/         # 定时任务模块
├── WxFbsir-system/         # 系统模块
├── WxFbsir-ui/             # 前端UI模块
├── sql/                    # 数据库脚本
├── pom.xml                 # 项目根pom文件
└── 部署文档.md             # 部署指南
```

## 二、核心配置文件

### 2.1 主节点配置文件 (`WxFbsir-admin/src/main/resources/application.yml`)

#### 项目基本配置
```yaml
wxfbsir:
  name: 福帮手                          # 项目名称
  version: 1.0.0                       # 项目版本
  copyrightYear: 2025                  # 版权年份
  profile: ${WXFBSIR_FILE_PATH:D:/WxFbsir/uploadPath}  # 文件上传路径
  addressEnabled: false                # 是否获取IP地址
  captchaType: math                    # 验证码类型（math数字计算, char字符验证）
  domain: ${WXFBSIR_DOMAIN:http://localhost:8080}  # 域名配置
```

#### WebSocket配置
```yaml
wxfbsir:
  websocket:
    enabled: true                      # 是否启用WebSocket服务
    path: /ws/engine                   # WebSocket端点路径（重要，勿随意更改）
    max-connections: 10000             # 最大连接数
    max-message-size: 1048576          # 最大消息大小（字节）
    heartbeat-interval: 30             # 心跳间隔（秒）
    heartbeat-timeout: 10              # 心跳超时时间（秒）
    session-cleanup-interval: 60       # 会话清理间隔（秒）
    message-queue-size: 10000          # 消息队列最大大小
```

#### 服务器配置
```yaml
server:
  port: 8080                           # 服务器端口
  servlet:
    context-path: /                    # 应用访问路径
  tomcat:
    uri-encoding: UTF-8                # URI编码
    accept-count: 1000                 # 连接数满后的排队数
    threads:
      max: 800                         # 最大线程数
      min-spare: 100                   # 初始化线程数
```

#### 数据库配置
```yaml
spring:
  datasource:
    type: com.alibaba.druid.pool.DruidDataSource
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/wxfbsir?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=true&serverTimezone=GMT%2B8
    username: root
    password: 
```

#### Redis配置
```yaml
spring:
  data:
    redis:
      host: ${WXFBSIR_REDIS_HOST:127.0.0.1}  # Redis地址
      port: ${WXFBSIR_REDIS_PORT:6379}       # Redis端口
      database: ${WXFBSIR_REDIS_DATABASE:0}  # 数据库索引
      password: ${WXFBSIR_REDIS_PASSWORD:}   # 密码
      timeout: 5s                              # 连接超时时间
      lettuce:
        pool:
          min-idle: 2                        # 最小空闲连接
          max-idle: 10                       # 最大空闲连接
          max-active: 20                     # 最大连接数
          max-wait: 5000ms                   # 最大等待时间
```

#### SpringDoc API文档配置
```yaml
springdoc:
  api-docs:
    path: /v3/api-docs
  swagger-ui:
    enabled: true
    path: /swagger-ui.html
    tags-sorter: alpha
  group-configs:
    - group: 'default'
      display-name: '测试模块'
      paths-to-match: '/**'
      packages-to-scan: com.wx.fbsir.web.controller.tool
```

### 2.2 前端配置文件 (`WxFbsir-ui/vite.config.js`)

#### 开发服务器配置
```javascript
server: {
  port: 80,                             // 前端访问端口
  host: true,                           // 允许外部访问
  open: true,                           // 自动打开浏览器
  proxy: {
    '/dev-api': {
      target: baseUrl,                  // 后端API代理地址
      changeOrigin: true,
      rewrite: (p) => p.replace(/^\/dev-api/, '')
    },
    '^/v3/api-docs/(.*)': {            // API文档代理
      target: baseUrl,
      changeOrigin: true,
    }
  }
}
```

#### 环境变量配置

Vite 使用项目根目录下的 `.env.development`、`.env.staging` 与 `.env.production`；当前 `vite.config.js` 通过 `loadEnv(mode, process.cwd())` 读取它们，未配置额外的 `envDir`。

### 2.3 引擎节点配置文件 (`WxFbsir-engine/src/main/resources/application.yml`)

#### 服务器配置
```yaml
server:
  port: 8081                           # 引擎节点端口（与Admin不同）
  servlet:
    context-path: /
```

#### Engine节点配置
```yaml
wxfbsir:
  engine:
    ws-url: ws://localhost:8080/ws/engine       # 默认主节点 WebSocket 地址；生产环境按实际域名改为 ws/wss
    host-id: engine-001                         # 主机ID（必须向管理员申请，并在白名单中配置为 hostType=engine）
    version: @engine.version@                   # 节点版本
    connection:
      timeout: 10000                            # 连接超时时间（毫秒）
      heartbeat-interval: 30                    # 心跳间隔（秒）
      heartbeat-timeout: 10                     # 心跳超时时间（秒）
    reconnect:
      enabled: true                             # 是否启用自动重连
      max-retries: 10                           # 最大重试次数
      initial-delay: 30                         # 初始重连延迟（秒）
      max-delay: 30                             # 最大重连延迟（秒）
```

#### Playwright配置
```yaml
wxfbsir:
  engine:
    playwright:
      enabled: true                             # 是否启用Playwright
      data-dir: /path/to/browser/data         # 浏览器数据目录
      headless: false                         # 是否无头模式
      pool:
        max-size: 10                          # 浏览器池最大大小
        min-idle: 2                           # 浏览器池最小空闲数
        session-timeout: 3600000              # 会话超时时间（毫秒）
      browser:
        launch-timeout: 60000                 # 启动超时时间（毫秒）
        navigation-timeout: 30000             # 导航超时时间（毫秒）
        viewport-width: 1280                  # 视口宽度
        viewport-height: 720                  # 视口高度
```

### 2.4 项目根配置 (`pom.xml`)

#### 项目基本信息
```xml
<groupId>com.wx.fbsir</groupId>
<artifactId>WxFbsir</artifactId>
<version>1.0.0</version>
<packaging>pom</packaging>
```

#### 依赖管理
```xml
<properties>
    <wxfbsir.version>1.0.0</wxfbsir.version>
    <java.version>17</java.version>
    <mybatis-spring-boot.version>3.0.4</mybatis-spring-boot.version>
    <druid.version>1.2.23</druid.version>
    <pagehelper.boot.version>2.1.1</pagehelper.boot.version>
    <fastjson.version>2.0.58</fastjson.version>
    <mysql.version>8.2.0</mysql.version>
    <springdoc.version>2.8.9</springdoc.version>
</properties>
```

Spring Boot 依赖 BOM 在根 `pom.xml` 中固定为 `3.5.4`；Engine 模块的独立版本通过 `WxFbsir-engine/pom.xml` 中的 `engine.version=1.3.1` 管理。

## 三、环境变量配置

### 3.1 系统环境变量
- `JAVA_HOME`: Java安装路径
- `MAVEN_HOME`: Maven安装路径
- `NODE_HOME`: Node.js安装路径

### 3.2 项目环境变量
- `WXFBSIR_REDIS_HOST`: Redis服务器地址
- `WXFBSIR_REDIS_PORT`: Redis服务器端口
- `WXFBSIR_REDIS_DATABASE`: Redis数据库索引
- `WXFBSIR_REDIS_PASSWORD`: Redis密码
- `WXFBSIR_FILE_PATH`: 文件上传路径
- `WXFBSIR_DOMAIN`: 项目域名
- `WXFBSIR_TOKEN_SECRET`: 令牌密钥
- `WXFBSIR_AES_SECRET_KEY`: AES加密密钥
- `GITEE_OAUTH_CLIENT_ID`: Gitee OAuth客户端ID
- `GITEE_OAUTH_CLIENT_SECRET`: Gitee OAuth客户端密钥

## 十四、配置注意事项

1. **安全配置**：
   - 生产环境务必使用环境变量配置敏感信息
   - 定期更换令牌密钥
   - 配置HTTPS

2. **性能配置**：
   - 根据服务器性能调整线程池大小
   - 合理配置缓存大小
   - 优化数据库连接池参数

3. **部署配置**：
   - Admin和Engine服务端口不能冲突
   - WebSocket连接地址配置正确
   - 主机ID唯一且已注册

4. **环境变量**：
   - 敏感信息通过环境变量配置
   - 避免硬编码配置信息
   - 配置默认值以保证开发便利性
