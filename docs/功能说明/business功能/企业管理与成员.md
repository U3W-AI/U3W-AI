# 企业管理与成员

本文档说明平台运营侧企业管理、企业成员管理、企业场景包分发（grant）与撤销（revoke）的功能与业务流程。

---

## 一、功能概述

企业（Enterprise）是 FBS 系统中的机构组织概念，用于场景包的批量分发和多成员管理。平台向企业分发（grant）场景包时，系统自动为该企业当前所有正常状态成员批量创建 member_pack 授权记录；企业新增成员时，也会自动继承该企业当前所有已授权的有效企业包。

**核心特性：**
- 企业与用户的归属关系只通过 `fbs_enterprise_member` 表维护，不修改 `sys_user` 表
- 企业包配额（packQuota/usedQuota）在企业包（fbs_enterprise_pack）层面统一管理
- 成员授权凭证（fbs_member_pack）仅记录成员是否有权使用某企业包，不承担独立配额
- 消费时从企业包配额扣减，不从成员授权记录扣减

## 二、企业管理

### 2.1 创建企业

**接口**：`POST /business/fbs/enterprise`

**请求体**：
```json
{
  "enterpriseName": "示例科技",
  "contact": "13800138000",
  "remark": "测试企业"
}
```

### 2.2 编辑企业

**接口**：`PUT /business/fbs/enterprise`

**请求体**：
```json
{
  "id": 1,
  "enterpriseName": "示例科技（已更名）"
}
```

### 2.3 禁用企业

**接口**：`PUT /business/fbs/enterprise/disable`

**请求体**：`{ "id": 1 }`

**前置条件**：status=1（正常）

**效果**：status → 2（已禁用），企业成员消费路径 fail-closed

### 2.4 查询企业列表

**接口**：`GET /business/fbs/enterprise/list`

**分页参数**：`pageNum`, `pageSize`, `enterpriseName`（模糊搜索）

## 三、企业成员管理

### 3.1 添加成员

**接口**：`POST /business/fbs/enterprise/member`

**请求体**：
```json
{
  "enterpriseId": 1,
  "userId": 1001,
  "role": "admin"
}
```

| 参数 | 说明 |
|------|------|
| enterpriseId | 企业ID |
| userId | 用户ID |
| role | 角色：admin/普通成员 |

**效果**：
- 在 `fbs_enterprise_member` 表插入记录
- 默认 status=1（正常）

### 3.2 移除成员

**接口**：`DELETE /business/fbs/enterprise/member/{id}`

**效果**：status → 2（已移除），成员消费路径 fail-closed

### 3.3 查询成员列表

**接口**：`GET /business/fbs/enterprise/member/list?enterpriseId={id}`

## 四、企业场景包分发与撤销

### 4.1 分发场景包（grant）

**接口**：`POST /business/fbs/enterprise/pack/grant`

**请求体**：
```json
{
  "enterpriseId": 1,
  "packCode": "pack_bookwriter",
  "packQuota": 100
}
```

| 参数 | 说明 |
|------|------|
| enterpriseId | 企业ID |
| packCode | 场景包编码 |
| packQuota | 配额数量（最大使用次数） |

**业务流程：**
1. 检查场景包是否存在且已发布
2. 创建/更新 `fbs_enterprise_pack` 记录（enterpriseId + packId → 唯一，packCode 冗余存储仅用于展示）
3. **先将企业下所有成员已有授权记录标记为已撤销（status=4）**
4. 批量创建新的 `fbs_member_pack` 授权记录（企业下所有正常成员，自动继承）

**配额模型**：
- packQuota：配额上限
- usedQuota：已使用次数
- remainQuota = packQuota - usedQuota

### 4.2 撤销场景包（revoke）

**接口**：`PUT /business/fbs/enterprise/pack/revoke`

**请求体**：`{ "id": 1 }`

**业务流程：**
1. 企业包 status → 3（已撤销）
2. 级联更新所有成员授权记录 status → 4（已撤销）

### 4.3 查询企业包列表

**接口**：`GET /business/fbs/enterprise/pack/list?enterpriseId={id}&status={status}`

## 五、Fail-Closed 校验链

成员消费时（hostType=ENTERPRISE）执行以下校验，任一失败则拒绝：

| 校验点 | 失败响应 | 说明 |
|--------|---------|------|
| 企业存在且正常 | 企业不存在/已禁用 | fbs_enterprise.status != 1 |
| 成员存在且正常 | 成员不存在/已移除 | fbs_enterprise_member.status != 1 |
| 企业包存在且正常 | 企业包不存在/已撤销 | fbs_enterprise_pack.status != 1 |
| 成员授权有效 | 成员未获此包授权 | fbs_member_pack.status != 1 |
| 企业配额充足 | 企业配额已用尽 | usedQuota >= packQuota |

## 六、数据模型

### fbs_enterprise 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| enterprise_name | VARCHAR(128) | 企业名称 |
| contact | VARCHAR(32) | 联系方式 |
| status | INT | 状态：1=正常, 2=已禁用 |
| del_flag | CHAR(1) | 删除标志 |

### fbs_enterprise_member 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| enterprise_id | BIGINT | 企业ID |
| user_id | BIGINT | 用户ID |
| role | VARCHAR(32) | 角色：admin/普通成员 |
| status | INT | 状态：1=正常, 2=已移除 |
| del_flag | CHAR(1) | 删除标志 |

### fbs_enterprise_pack 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| enterprise_id | BIGINT | 企业ID |
| pack_id | BIGINT | 场景包ID（冗余便于查询） |
| pack_code | VARCHAR(64) | 场景包编码 |
| pack_quota | INT | 配额上限 |
| used_quota | INT | 已使用次数 |
| status | INT | 状态：1=正常, 3=已撤销 |
| del_flag | CHAR(1) | 删除标志 |

### fbs_member_pack 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| member_id | BIGINT | 成员ID（fbs_enterprise_member.id） |
| enterprise_pack_id | BIGINT | 企业包ID |
| pack_id | BIGINT | 场景包ID（冗余便于查询） |
| grant_time | DATETIME | 授权时间 |
| expiry_time | DATETIME | 过期时间（NULL=永不过期） |
| status | INT | 状态：1=正常, 2=已用尽, 3=已过期, 4=已撤销 |
| del_flag | CHAR(1) | 删除标志 |

**重要**：fbs_member_pack 是纯授权凭证，不存独立配额。配额扣减统一在 fbs_enterprise_pack.packQuota/usedQuota 层面。
