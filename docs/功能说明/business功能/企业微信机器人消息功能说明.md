# 企业微信机器人消息功能说明

企业微信机器人消息推送功能，支持向微信群发送模板消息、文本消息和提示词更新通知。

## 功能概述

企业微信机器人消息功能提供了一套完整的消息推送解决方案，主要包括：

1. **Webhook 管理**：管理企业微信机器人的 Webhook 地址配置
2. **消息推送**：支持向微信群发送文本消息和模板卡片消息
3. **提示词通知**：支持发送提示词修改请求通知

---

## 使用场景

- **新咨询通知**：当用户提交新的咨询需求时，自动推送到微信群
- **提示词修改通知**：当用户需要修改系统提示词时，发送通知到微信群

---

## 配置说明

### 1. 企业微信机器人配置

1. 在企业微信群中添加群机器人
2. 复制机器人的 Webhook 地址
3. 在系统中配置 Webhook 信息

### 2. 系统配置

在 `application.yml` 中配置提示词编辑器链接：

```yaml
wechat:
  prompt-editor-url: ${PROMPT_EDITOR_URL:https://your-domain.com/systemPrompt}
```

## 接口说明

### 后端接口

| 接口地址 | 请求方式 | 功能说明 |
|---------|---------|---------|
| `/business/message/list` | GET | 获取 Webhook 列表 |
| `/business/message/get` | GET | 获取 Webhook 详情 |
| `/business/message/insert` | POST | 新增 Webhook |
| `/business/message/update` | POST | 修改 Webhook |
| `/business/message/delete` | POST | 删除 Webhook |
| `/business/message/send` | POST | 发送消息到微信群 |
| `/business/message/updateprompt` | POST | 发送提示词更新通知 |

### 前端接口

位于 `WxFbsir-ui/src/api/business/airobotmessage/wecomWebhook.js`

```javascript
// 查询企业微信 Webhook 列表
export function listWecomWebhook()

// 查询企业微信 Webhook 详情
export function getWecomWebhook(id)

// 新增企业微信 Webhook
export function addWecomWebhook(data)

// 修改企业微信 Webhook
export function updateWecomWebhook(data)

// 删除企业微信 Webhook
export function delWecomWebhook(id)
```

## 数据库设计

### 数据表：`wc_webhook_url`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT | 主键ID |
| name | VARCHAR(100) | Webhook名称（唯一） |
| webhook_url | VARCHAR(512) | 企业微信Webhook地址 |
| description | VARCHAR(255) | 描述信息 |
| status | TINYINT | 状态：1-启用，0-禁用 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

## 使用示例

### 1. 配置 Webhook

在管理后台的"企业微信机器人"页面：
1. 点击"新增"按钮
2. 填写 Webhook 名称和地址
3. 选择启用状态
4. 保存配置

### 2. 发送消息

调用发送消息接口：

```java
// 发送模板消息
messageService.sendTemplateMessage("用户ID", "消息内容");

```

### 3. 消息格式

**文本消息格式：**
```json
{
  "msgtype": "text",
  "text": {
    "content": "用户名：xxx\n内容：xxx\n时间：2026-03-07 10:00:00"
  }
}
```

**模板卡片消息格式：**
```json
{
  "msgtype": "template_card",
  "template_card": {
    "card_type": "text_notice",
    "main_title": {"title": "新咨询需求"},
    "sub_title_text": "用户名：xxx\n需求：xxx",
    "horizontal_content_list": [
      {"keyname": "时间", "value": "2026-03-07 10:00:00"}
    ],
    "card_action": {"type": 1, "url": "https://work.weixin.qq.com"}
  }
}
```

---

## 注意事项

1. **Webhook 安全**：妥善保管 Webhook 地址，避免泄露
2. **频率限制**：企业微信机器人有发送频率限制，请注意控制发送频率
3. **消息格式**：支持文本消息和模板卡片消息，根据场景选择合适的格式
4. **状态管理**：禁用状态的 Webhook 不会发送消息
