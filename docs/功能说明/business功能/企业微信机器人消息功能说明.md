## 功能概述

企业微信机器人消息功能提供了一套完整的消息推送解决方案，主要包括：

1. **Webhook 管理**：管理企业微信机器人的 Webhook 地址配置
2. **消息推送**：支持向微信群发送文本消息和模板卡片消息
3. **提示词通知**：支持发送提示词修改请求通知
4. **异步发送**：支持异步消息发送，提高系统响应速度
5. **重试机制**：消息发送失败时自动重试，提高可靠性

---

## 使用场景

- **新咨询通知**：当用户提交新的咨询需求时，自动推送到微信群
- **提示词修改通知**：当用户需要修改系统提示词时，发送通知到微信群

## 配置说明

### 1. 企业微信机器人配置

1. 在企业微信群中添加“消息推送”并复制 Webhook 地址
2. 在系统中配置 Webhook 信息

### 2. 系统配置

在 `application.yml` 中配置提示词编辑器链接：

```yaml
wechat:
  prompt-editor-url: ${PROMPT_EDITOR_URL:https://your-domain.com/content/systemPrompt}
```

## 核心特性

### 1. 单例 HttpClient

使用单例 HttpClient 实例，避免重复创建对象，提高性能：

```java
private static final HttpClient httpClient = HttpClient.newHttpClient();
```

### 2. 重试机制

消息发送失败时自动重试，最多重试1次：

```java
private void sendHttpRequest(String webhookUrl, String json) throws Exception {
    int maxRetries = 1;
    int retries = 0;
    
    while (retries <= maxRetries) {
        try {
            // 发送请求
            httpClient.send(request, HttpResponse.BodyHandlers.ofString());
            return;
        } catch (Exception e) {
            retries++;
            if (retries > maxRetries) {
                throw e;
            }
            Thread.sleep(1000); // 等待1秒后重试
        }
    }
}
```

### 3. 异步发送

支持异步消息发送，不阻塞主线程：

```java
// 异步发送文本消息
public void sendTextMessageAsync(String userId, String messageContent) {
    CompletableFuture.runAsync(() -> {
        try {
            sendTextMessage(userId, messageContent);
        } catch (Exception e) {
            logger.error("异步发送文本消息失败", e);
        }
    });
}
```

### 4. 参数校验

接口层进行参数校验，确保数据完整性：

```java
if (id == null) {
    return AjaxResult.error("Webhook ID不能为空");
}
if (wecomWebhook.getName() == null || wecomWebhook.getName().trim().isEmpty()) {
    return AjaxResult.error("Webhook 名称不能为空");
}
```

### 5. 日志记录

完善的日志记录，便于问题排查：

```java
logger.info("开始发送文本消息，用户ID：{}", userId);
logger.error("发送消息失败，已达到最大重试次数", e);
logger.warn("发送消息失败，正在重试 ({}/{})", retries, maxRetries);
```

## 使用示例

### 1. 配置 Webhook

在管理后台的"企业微信机器人"页面：
1. 点击"新增"按钮
2. 填写 Webhook 名称和地址
3. 选择启用状态
4. 保存配置

### 2. 发送消息

**同步发送：**
```java
// 发送模板消息（指定 Webhook ID）
// Webhook ID是指项目系统中企业微信Webhook表中的ID值
messageService.sendTemplateMessage("用户ID", "消息内容", webhookId);
```

**异步发送：**
```java
// 异步发送模板消息
messageService.sendTemplateMessageAsync("用户ID", "消息内容", webhookId);
```

### 3. 消息格式

**文本消息格式：**
```json
{
  "msgtype": "text",
  "text": {
    "content": "用户名：xxx\n内容：xxx\n时间：2026-03-10 10:00:00"
  }
}
```

**模板卡片消息格式：**
```json
{
  "msgtype": "template_card",
  "template_card": {
    "card_type": "text_notice",
    "main_title": {"title": "新咨询需求"},
    "sub_title_text": "用户名：xxx\n需求：xxx",
    "horizontal_content_list": [
      {"keyname": "时间", "value": "2026-03-10 10:00:00"}
    ],
    "card_action": {"type": 1, "url": "https://work.weixin.qq.com"}
  }
}
```

## 注意事项

1. **Webhook 安全**：妥善保管 Webhook 地址，避免泄露
2. **频率限制**：企业微信机器人有发送频率限制，请注意控制发送频率
3. **消息格式**：支持文本消息和模板卡片消息，根据场景选择合适的格式
4. **状态管理**：禁用状态的 Webhook 不会发送消息
5. **重试机制**：消息发送失败会自动重试1次，间隔1秒
6. **异步发送**：异步发送失败时只记录日志，不抛出异常
