## 🎯 功能概述

### 什么是日更助手？

**日更助手**是一个基于AI大模型的公众号文章生成系统，通过集成腾讯元器智能体平台，帮助用户快速生成高质量的文章内容。

### 核心特性

- ✅ **多模型协同生成**  
  同时调用3个大模型（混元、DeepSeek、精调模型）生成不同风格的初稿，用户可自主选择参与的模型

- ✅ **智能内容整合**  
  使用混元优化大模型整合多个版本，生成最优质的文章内容

- ✅ **异步处理架构**  
  后台异步调用AI生成，前端轮询获取状态，用户无需等待

- ✅ **智能排版**  
  支持调用腾讯元器排版工作流，自动优化文章格式和结构

- ✅ **公众号投递**  
  一键投递优化后的文章到微信公众号草稿箱

- ✅ **历史记录管理**  
  保存所有生成的文章，支持查看、编辑和删除

```java
public DailyArticle createArticleAndOptimize(Long userId, String articleTitle, String selectedModels) {

@Async("asyncTaskExecutor")
public void processArticleOptimizationAsync(Long articleId, Long userId, String articleTitle) {
    // 获取用户的元器配置
    YuanqiAgentConfig config = yuanqiAgentConfigService.selectActiveConfigByUserId(userId);
    
    // 调用腾讯元器API
    YuanqiApiResponse response = yuanqiAgentApiService.optimizeArticle(
        config.getApiKey(),
        config.getAgentId(),
        String.valueOf(userId),
        articleTitle,
        articleId
    );
    
    if (response.isSuccess()) {
        // 任务已提交，记录taskId，等待工作流回调
        updateArticleStatus(articleId, 0, null, null, response.getTaskId());
        
        // 启动5分钟超时检查
        scheduleCallbackTimeoutCheck(articleId, articleTitle);
    } else {
        updateArticleStatus(articleId, 2, response.getErrorMessage(), null, null);
    }
}
```

```java
public YuanqiApiResponse optimizeArticle(String appKey, String appId, String userId, 
                                         String articleTitle, Long articleId) {
    // 构建请求头
    HttpHeaders headers = new HttpHeaders();
    headers.setContentType(MediaType.APPLICATION_JSON);
    headers.set("Authorization", "Bearer " + appKey);
    
    // 构建请求体
    Map<String, Object> requestBody = new HashMap<>();
    requestBody.put("assistant_id", appId);
    requestBody.put("user_id", userId);
    requestBody.put("stream", false);
    
    // 构建消息：发送JSON格式的参数
    List<Map<String, Object>> messages = new ArrayList<>();
    Map<String, Object> userMessage = new HashMap<>();
    userMessage.put("role", "user");
    
    // 消息内容：{"articleTitle": "西瓜", "articleId": 83}
    String jsonMessage = String.format(
        "{\"articleTitle\":\"%s\",\"articleId\":%d}", 
        articleTitle, articleId
    );
    
    List<Map<String, Object>> contentList = new ArrayList<>();
    Map<String, Object> textContent = new HashMap<>();
    textContent.put("type", "text");
    textContent.put("text", jsonMessage);
    contentList.add(textContent);
    
    userMessage.put("content", contentList);
    messages.add(userMessage);
    requestBody.put("messages", messages);
    
    // 发送请求
    HttpEntity<Map<String, Object>> requestEntity = new HttpEntity<>(requestBody, headers);
    ResponseEntity<String> response = restTemplate.exchange(
        "https://yuanqi.tencent.com/openapi/v1/agent/chat/completions",
        HttpMethod.POST,
        requestEntity,
        String.class
    );
    
    // 解析响应，获取taskId
    return parseResponse(response.getBody());
}
```

### 4. 前端状态轮询

**dailyAssistant.vue**

当前实现是**基于文章列表的轮询刷新**，而不是单独调用一个 `getArticleStatus` 接口。核心逻辑如下：

```javascript
// 创建文章并触发轮询
const handleCreate = async () => {
  // ... 省略参数校验与接口调用
  const response = await createAndOptimize(title, selectedModels.value)
  if (response.code === 200) {
    const newArticleId = response.data?.id
    // 刷新列表并选中新文章
    await loadArticles()
    if (newArticleId) {
      const newArticle = articles.value.find(a => a.id === newArticleId)
      if (newArticle) {
        selectedArticle.value = newArticle
      }
      // 启动轮询，监控生成进度
      startPollingArticle(newArticleId, title)
    }
  }
}

// 轮询单篇文章的生成状态（通过刷新文章列表）
const startPollingArticle = (articleId, articleTitle) => {
  let pollCount = 0
  const maxPolls = 60  // 5分钟（60 * 5秒 = 300秒）
  
  const pollInterval = setInterval(async () => {
    pollCount++
    try {
      // 刷新列表，获取最新的文章内容和状态
      await loadArticles()
      const article = articles.value.find(a => a.id === articleId)
      
      if (article) {
        // 同步更新右侧选中内容
        if (selectedArticle.value && selectedArticle.value.id === articleId) {
          selectedArticle.value = article
        }
        
        if (article.processStatus === 1) {
          // 成功
          clearInterval(pollInterval)
          ElMessage({
            message: `文章"${articleTitle}"生成完成！`,
            type: 'success',
            duration: 3000
          })
        } else if (article.processStatus === 2) {
          // 失败
          clearInterval(pollInterval)
          ElMessage({
            message: `文章"${articleTitle}"生成失败：${article.errorMessage || '未知错误'}`,
            type: 'error',
            duration: 5000
          })
        }
        // status = 0 时继续轮询，用户可以边看已生成的模型内容
      } else if (pollCount >= maxPolls) {
        // 超时（超过5分钟）
        clearInterval(pollInterval)
        ElMessage({
          message: `文章"${articleTitle}"生成超时（超过5分钟），请检查文章状态`,
          type: 'warning',
          duration: 5000
        })
      }
    } catch (error) {
      console.error('轮询失败:', error)
    }
  }, 5000) // 每5秒刷新一次文章列表
}
```

```java
@PostMapping("/publishToWechat")
public AjaxResult publishToWechat(@RequestBody Map<String, Object> params) {
    Long articleId = Long.parseLong(params.get("articleId").toString());
    String contentType = params.get("contentType").toString();

    // 只支持投递排版后的文章
    if (!"layout".equals(contentType)) {
        return error("仅支持投递排版后的文章");
    }

    // 查询文章
    DailyArticle article = dailyArticleService.selectDailyArticleById(articleId);
    if (article == null) {
        return error("文章不存在");
    }

    // 获取用户 UnionId
    Long userId = getUserId();
    String unionId = userInfoMapper.getUnionIdByUserId(String.valueOf(userId));
    if (unionId == null || unionId.trim().isEmpty()) {
        return error("未找到用户信息，请先登录微信");
    }

    // 获取排版后的 HTML 内容
    Object layoutedContentObj = params.get("layoutedContent");
    if (layoutedContentObj == null) {
        return error("排版内容为空，无法投递");
    }
    String originalContent = layoutedContentObj.toString();

    // 提取标题（优先使用排版内容中的标题，否则退回到原始文章标题）
    String baseTitle = article.getArticleTitle();
    String extractedTitle = extractTitleFromLayoutContent(originalContent);
    String finalTitle = (extractedTitle != null && !extractedTitle.trim().isEmpty())
            ? extractedTitle.trim()
            : baseTitle;

    // 去除正文中的标题，避免与公众号标题重复
    String content = removeTitleFromContent(originalContent);

    // 将纯文本内容转换为 HTML（如果排版结果中 HTML 标签不够丰富）
    content = convertTextToHtml(content);
    if (content == null || content.trim().isEmpty()) {
        return error("内容为空，无法投递");
    }

    // 调用公众号投递服务
    Map<String, Object> publishParams = new HashMap<>();
    publishParams.put("unionId", unionId);
    publishParams.put("title", finalTitle);
    publishParams.put("contentText", content);
    publishParams.put("shareUrl", "");
    publishParams.put("thumbMediaId", null);

    ResultBody result = wechatMpService.publishToOffice(publishParams);

    if (result.getCode() == 200) {
        // 更新发布次数（空值安全处理）
        Integer publishCount = article.getPublishCount();
        if (publishCount == null) {
            publishCount = 0;
        }
        article.setPublishCount(publishCount + 1);
        dailyArticleService.updateDailyArticle(article);
        return success(result.getData());
    } else {
        return error(result.getMessages());
    }
}
```

## ⚙️ 腾讯元器工作流配置

### 工作流设计方案

在腾讯元器平台创建一个**文章生成工作流**，实现以下功能：

1. 接收参数（articleTitle、articleId）
2. 并行调用选中的大模型生成初稿
3. HTTP回调保存各模型内容
4. 混元优化大模型整合优化
5. HTTP回调保存优化内容

### 工作流节点配置

#### 节点1：参数提取

**节点类型**：参数提取节点

**配置**：
```json
{
  "extractFrom": "user_message",
  "parameters": [
    {
      "name": "articleTitle",
      "type": "string",
      "required": true
    },
    {
      "name": "articleId",
      "type": "number",
      "required": true
    }
  ]
}
```

**说明**：从用户消息中提取JSON参数
```json
{"articleTitle": "人工智能", "articleId": 88}
```

#### 节点2：模型1 - 混元大模型

**节点类型**：大模型调用

**提示词**：
```
请根据以下文章标题，生成一篇完整的公众号文章内容：

标题：{{articleTitle}}

要求：
1. 内容要有深度和价值，800-1200字
2. 结构清晰，包含引言、正文、结尾
3. 语言生动，适合公众号阅读
4. 可以加入案例或数据支持
5. 不要输出markdown格式，使用纯文本
```

**输出变量**：`model1_output` 

#### 节点3：HTTP回调 - 保存模型1内容

**节点类型**：HTTP请求

**配置**：
```yaml
URL: http://你的服务器地址:8080/system/daily-article/saveModelContent
方法: POST
Content-Type: application/json

请求体:
{
  "articleId": {{articleId}},
  "modelName": "混元大模型",
  "content": {{model1_output}},
  "modelIndex": 1
}
```

#### 节点4-7：模型2、模型3及其回调

配置同上，修改：
- 模型2（DeepSeek）：`modelIndex: 2` 
- 模型3（精调模型）：`modelIndex: 3` 

#### 节点8：混元优化大模型

**节点类型**：大模型调用

**提示词**：
```
你现在是一位资深的内容编辑，请根据以下3个大模型生成的文章初稿，整合优化出一篇最优质的公众号文章。

文章标题：{{articleTitle}}

【模型1初稿】
{{model1_output}}

【模型2初稿】
{{model2_output}}

【模型3初稿】
{{model3_output}}

要求：
1. 吸收3个版本的优点，去除缺点
2. 保持结构清晰，逻辑连贯
3. 语言优美，适合公众号阅读
4. 控制在800-1200字
5. 不要输出markdown格式，使用纯文本
```

**输出变量**：`optimized_output` 

#### 节点9：HTTP回调 - 保存优化内容

**配置**：
```yaml
URL: http://你的服务器地址:8080/system/daily-article/updateOptimizedContent
方法: POST
Content-Type: application/json

请求体:
{
  "articleId": {{articleId}},
  "optimizedContent": {{optimized_output}}
}
```

### 工作流执行流程图

```
开始
  ↓
参数提取（articleTitle, articleId）
  ↓
┌─────────┬─────────┬─────────┐
│         │         │         │
模型1     模型2     模型3
生成      生成      生成
│         │         │         │
HTTP回调  HTTP回调  HTTP回调
保存      保存      保存
│         │         │         │
└─────────┴─────────┴─────────┘
           ↓
    混元优化大模型
    整合优化
           ↓
    HTTP回调保存
    优化内容
           ↓
         结束
```

### 重要配置说明

#### 1. HTTP回调地址

**开发环境**：
- 如果服务器在本地，需要使用**内网穿透工具**（花生壳、OpenFrp等）
- 获取公网URL后配置到工作流

**生产环境**：
- 使用服务器的公网IP或域名
- 示例：`http://your-domain.com:8080/system/daily-article/saveModelContent` 

#### 2. 白名单配置

需要在项目的 Spring Security 配置中**显式允许上述回调接口匿名访问**，否则腾讯元器工作流将无法成功回调。具体实现方式取决于项目当前的安全配置类（例如在自定义的 Security 配置中为：

- `/system/daily-article/saveModelContent` 
- `/system/daily-article/updateOptimizedContent` 

添加对应的 `permitAll` 规则）。

#### 3. 超时处理

- 工作流执行超时时间：建议5分钟
- 后端5分钟超时检查：如果未收到回调，自动标记为失败

## 🔑 获取腾讯元器配置信息

在使用日更助手之前，需要从腾讯元器平台获取必要的配置信息。以下是详细的获取步骤：

### 1. 获取 API 密钥（appKey）

#### 步骤：

1. **登录腾讯元器平台**  
   访问 [https://yuanqi.tencent.com](https://yuanqi.tencent.com) 并登录

2. **进入智能体管理**  
   在左侧菜单中找到你创建的智能体（日更助手）

3. **进入应用发布服务状态页面**  
   - 点击智能体右上角的"发布"或"应用状态"按钮
   - 进入应用发布服务状态管理页面

4. **打开 API 管理**  
   - 在应用发布服务状态页面中，找到"API 管理"选项卡
   - 点击进入 API 管理页面

5. **创建或查看 API 密钥**  
   - 如果还没有密钥，点击"创建密钥"按钮
   - 系统会生成一个 `appKey`（API 密钥）
   - **⚠️ 重要**：密钥只显示一次，请立即复制保存
   - 格式类似：`sk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

> API 密钥获取页面截图未随仓库发布，请以当前平台页面为准。

### 2. 获取智能体 ID（appID / assistant_id）

#### 方法一：从体验链接中提取（推荐）

1. **获取体验链接**  
   - 在智能体管理页面，点击"体验"或"分享"按钮
   - 复制生成的体验链接

2. **提取 appID**  
   体验链接格式如下：
   ```
   https://yuanqi.tencent.com/webim/#/chat/mJsohw?appid=1996840394248028544&experience=true&space_id=123
   ```
   
   从 URL 中提取 `appid=` 后面的数字，即为智能体 ID：
   ```
   appID: 1996840394248028544
   ```

#### 方法二：从 API 管理页面获取

1. 在 API 管理页面，通常会显示当前智能体的 `assistant_id`
2. 直接复制该 ID

### 3. 配置到系统中

获取到 `appKey` 和 `appID` 后，在系统中进行配置：

1. **登录福帮手系统**
   访问：http://localhost:80（或你的实际地址）

2. **进入日更助手页面**  
   点击左侧菜单"工具" → "日更助手"

3. **打开配置窗口**  
   点击页面右上角"配置智能体"或"元器配置"按钮

4. **填写配置信息**
   ```yaml
   智能体名称: 日更助手（自定义名称）
   智能体ID: 1996840394248028544（从体验链接提取的 appID）
   API 密钥: sk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx（从 API 管理获取的 appKey）
   API 端点: https://yuanqi.tencent.com/openapi/v1/agent/chat/completions（默认）
   ```

5. **保存配置**  
   点击"保存"按钮，系统会提示"配置成功"

### 4. 验证配置

配置完成后，可以通过以下方式验证：

1. 创建一篇测试文章
2. 观察文章是否正常进入"处理中"状态
3. 等待 2-3 分钟，查看是否生成内容
4. 如果生成失败，检查：
   - appID 是否正确（从体验链接中仔细提取）
   - API 密钥是否正确（注意不要多复制空格）
   - 工作流是否已发布
   - 内网穿透是否正常工作

### 常见问题

**Q: 如何确认 appID 是否正确？**  
A: 可以尝试访问体验链接，如果能正常打开智能体对话界面，说明 appID 有效。

**Q: API 密钥忘记了怎么办？**  
A: 密钥只显示一次，忘记后需要在 API 管理页面删除旧密钥，重新创建新密钥。

**Q: 配置后提示"unauthorized"错误？**  
A: 检查 API 密钥是否正确，或者密钥是否已被删除/禁用。

## 📖 使用说明

### 1. 创建文章

1. 登录系统，进入**工具** → **日更助手**
2. 点击"新建文章"
3. 输入文章标题（例如："人工智能的发展趋势"）
4. 选择参与的大模型（可选1-3个）
5. 点击"开始创作"
6. 系统提示"文章创建成功，AI内容正在生成中"

### 2. 查看生成进度

- 文章列表会显示处理状态：
  - 🟡 **处理中**：AI正在生成内容
  - 🟢 **已完成**：内容已生成
  - 🔴 **失败**：生成失败，查看错误信息

- 前端大约每5秒自动刷新文章列表，并在最多约5分钟内持续轮询状态

### 3. 查看文章内容

点击"查看详情"，可以看到：
- **优化内容**：混元优化后的最终版本
- **模型1初稿**：混元大模型生成的版本
- **模型2初稿**：DeepSeek生成的版本
- **模型3初稿**：精调模型生成的版本

### 4. 智能排版

1. 选择要排版的内容（优化内容或某个模型初稿）
2. 点击"智能排版"
3. 等待排版完成（约10-30秒）
4. 预览排版后的效果

### 5. 投递到公众号

1. 点击"投递到公众号"
2. 系统自动：
   - 提取文章标题
   - 转换为HTML格式
   - 投递到微信公众号草稿箱
3. 登录公众号后台即可看到草稿

### 6. 历史管理

- 查看所有创建的文章
- 删除不需要的文章
- 查看发布次数

## ❓ 常见问题

### Q1: 工作流执行后，后端没有收到回调？

**可能原因**：
1. HTTP回调地址配置错误
2. 服务器在内网，腾讯元器无法访问
3. 白名单配置缺失

**解决方案**：
1. 检查工作流HTTP节点的URL是否正确
2. 使用内网穿透工具获取公网地址
3. 确认 `SecurityConfig.java` 中已配置白名单

### Q2: 文章状态一直是"处理中"？

**可能原因**：
1. 工作流执行失败
2. HTTP回调失败
3. 超过5分钟超时

**解决方案**：
1. 登录腾讯元器平台，查看工作流执行日志
2. 检查后端日志，确认是否收到回调
3. 重新创建文章

### Q3: 某个模型的内容为空？

**可能原因**：
1. 该模型未被选中
2. 工作流配置错误
3. HTTP回调参数错误

**解决方案**：
1. 检查创建文章时是否勾选了该模型
2. 查看工作流日志，确认该模型节点是否执行
3. 检查HTTP回调的 `modelIndex` 是否正确

### Q4: 投递到公众号失败？

**可能原因**：
1. 未绑定微信公众号
2. UnionId获取失败
3. 公众号权限不足

**解决方案**：
1. 确保已登录微信
2. 检查用户信息表中是否有 `union_id` 
3. 确认公众号已认证，且有草稿箱权限

### Q5: 如何修改大模型提示词？

在腾讯元器工作流中：
1. 找到对应的大模型节点
2. 编辑提示词内容
3. 保存并重新发布工作流

### Q6: 如何增加或减少模型数量？

**后端**：
- 修改 `DailyArticleMapper.xml` 中的字段映射
- 添加对应的 `model4_content`、`model4_name` 等字段

**工作流**：
- 添加新的大模型节点
- 添加对应的HTTP回调节点
- 修改 `modelIndex` 参数

**前端**：
- 修改模型选择组件
- 添加新的模型选项

### Q7: 如何调整超时时间？

**工作流超时**：
- 在腾讯元器工作流设置中调整

**后端超时检查**：
```java
// DailyArticleServiceImpl.java
private void scheduleCallbackTimeoutCheck(Long articleId, String articleTitle) {
    scheduler.schedule(() -> {
        // 检查逻辑
    }, 5, TimeUnit.MINUTES); // 修改这里的时间
}
```

### Q8: 如何查看详细日志？

**后端日志**：
```bash
tail -f logs/FBSir-admin.log
```

**工作流日志**：
- 登录腾讯元器平台
- 进入工作流详情
- 查看执行历史和日志
