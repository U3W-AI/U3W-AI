# 场景包管理

本文档说明平台运营侧场景包管理的功能、业务流程和数据模型。

---

## 一、功能概述

场景包（Scene Pack）是 FBS 系统的核心产品单元，定义了一组技能的集合及对应的积分规则。平台运营人员可以创建、编辑、发布、下架场景包，用户通过授权码激活或直接领取来获得使用权限。

**核心特性：**
- 场景包是一个包含多个技能的集合（如"写书助手"包含 bookwriter 技能）
- 每个场景包绑定一个积分规则（pointsRuleCode），决定消费时扣减多少积分
- contentSnapshot 存储技能的完整 JSON 配置，Skill 端通过 `/fbs/skill-api/scene-pack/query` 获取
- 支持平台包（ownerType=1）和企业包（ownerType=2）两种归属类型

---

## 二、场景包状态机

```
草稿(0) → 已发布(1) → 已下架(2)
```

| 状态值 | 名称 | 说明 |
|--------|------|------|
| 0 | 草稿 | 正在编辑，尚未发布，用户不可见 |
| 1 | 已发布 | 正常对外，可被授权/领取 |
| 2 | 已下架 | 不再对外，存量用户不受影响 |

**规则：**
- 创建时默认 status=0（草稿）
- 只有 status=1 的包才能生成授权码
- 下架后授权码激活路径 fail-closed（授权码状态正常但包已下架，返回错误）

---

## 三、积分规则

场景包通过 `pointsRuleCode` 关联积分规则，消费时后端根据 `packCode → pointsRuleCode → wx_points_rule.points_value` 自动计算扣积分数值，调用方不能指定。

**免费包判断**：`pointsRuleCode = NULL` 表示免费包，consume 时不扣积分。

**规则编码示例：**

| pointsRuleCode | 说明 | pointsValue |
|----------------|------|-------------|
| `rule_bookwriter` | 写书助手积分规则 | 扣 10 分/次 |
| `NULL` | 免费包 | 不扣分 |

## 四、数据模型

### fbs_scene_pack 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| pack_code | VARCHAR(64) | 场景包编码（唯一） |
| pack_name | VARCHAR(128) | 场景包名称 |
| pack_type | INT | 包类型（1=标准包） |
| owner_type | INT | 归属：1=平台, 2=企业 |
| owner_id | BIGINT | 归属者ID（平台包为 NULL） |
| description | TEXT | 描述 |
| points_rule_code | VARCHAR(64) | 积分规则编码（NULL=免费） |
| visible_scope | VARCHAR(32) | 可见范围：ALL/PRIVATE |
| status | INT | 状态：0=草稿, 1=已发布, 2=已下架 |
| current_version | VARCHAR(32) | 当前版本号 |
| content_snapshot | TEXT | 技能配置快照（JSON字符串） |
| del_flag | CHAR(1) | 删除标志：0=存在, 2=删除 |

## 五、运营操作

### 5.1 创建场景包

**接口**：`POST /business/fbs/scene-pack`

**请求体**：
```json
{
  "packCode": "pack_bookwriter",
  "packName": "写书助手",
  "packType": 1,
  "description": "AI辅助写作全家桶",
  "pointsRuleCode": "rule_bookwriter",
  "visibleScope": "ALL"
}
```

**说明**：
- packCode 是唯一标识，创建后不可修改
- 创建后 status=0（草稿），需发布后才能对外

### 5.2 编辑场景包

**接口**：`PUT /business/fbs/scene-pack`

**说明**：
- 只允许编辑基本信息（packName、description、pointsRuleCode 等）
- packCode 创建后不可更改
- 已发布的包可以继续编辑，但已生成的授权码不受影响

### 5.3 发布场景包

**接口**：`PUT /business/fbs/scene-pack/publish`

**请求体**：`{ "id": 1 }`

**前置条件**：status=0（草稿）

**效果**：status → 1（已发布），可被授权/领取

### 5.4 下架场景包

**接口**：`PUT /business/fbs/scene-pack/unpublish`

**请求体**：`{ "id": 1 }`

**前置条件**：status=1（已发布）

**效果**：status → 2（已下架），授权码激活路径 fail-closed

## 六、Skill API 查询

场景包的 contentSnapshot 供 Skill 端通过 Skill API 查询：

**接口**：`POST /fbs/skill-api/scene-pack/query`

**请求**：
```json
{ "packCode": "pack_bookwriter" }
```

**响应**：
```json
{
  "code": 200,
  "data": {
    "packCode": "pack_bookwriter",
    "packName": "写书助手",
    "currentVersion": "1.0.0",
    "status": 1,
    "pointsRuleCode": "rule_bookwriter",
    "contentSnapshot": "{...JSON规则内容...}"
  }
}
```

**说明**：contentSnapshot 是原始 JSON 字符串，不做二次结构化转换，由 Skill 端负责解析。
