# 用户权益与自助服务

本文档说明用户侧自助服务（`/my/**`）的功能：查看我的权益、激活授权码、领取平台场景包。

---

## 一、功能概述

`/my/**` 接口是用户自助入口，需要 JWT 登录态，从 SecurityContext 获取当前用户 ID。运营人员无法通过这些接口操作他人数据。

**核心特性：**
- 所有接口需要登录态，自动获取当前用户
- 激活/领取支持幂等（重复操作返回成功，不报错）
- 授权码激活由授权码本身找到目标包，用户无需知道 packCode

---

## 二、我的权益列表

**接口**：`GET /my/packs`

**请求参数**（分页）：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| pageNum | int | 否 | 页码，默认 1 |
| pageSize | int | 否 | 每页条数，默认 10 |
| status | int | 否 | 权益状态：1=有效, 2=已过期, 3=已撤销，空=全部 |
| packId | Long | 否 | 场景包ID精确过滤 |
| sourceType | int | 否 | 来源类型：1=平台分发, 2=企业分发, 3=用户激活，空=全部 |

**返回字段**：
| 字段 | 说明 |
|------|------|
| id | 权益记录ID |
| packId | 场景包ID |
| packName | 场景包名称 |
| packCode | 场景包编码 |
| packVersion | 版本 |
| activatedAt | 激活时间 |
| expiresAt | 到期时间 |
| sourceType | 来源类型：1=平台分发, 2=企业分发, 3=用户激活 |
| sourceTypeDesc | 来源中文描述 |
| status | 权益状态：1=有效, 2=已过期, 3=已撤销 |
| statusDesc | 状态中文描述（综合考虑权益状态和场景包状态） |
| authCodeId | 授权码ID（sourceType=3 时有值） |
| packStatus | 场景包状态：1=上架, 0=草稿, 2=已下架（null=场景包已删除） |

**数据隔离**：只返回当前用户的权益记录。

## 三、激活授权码

**接口**：`POST /my/auth-code/activate`

**请求体**：`{ "authCode": "FBS-XXXXXXXXXXXX" }`

### 3.1 业务流程（Fail-Closed 校验链）

1. **幂等检查**：用户是否已有该包有效权益（status=1）→ 有则返回 `ALREADY_ACTIVATED`（HTTP 200）
2. **AUTH_CODE_INVALID** — 授权码不存在
3. **AUTH_CODE_DISABLED** — available != 1
4. **AUTH_CODE_REVOKED** — status = 4（已撤销）
5. **AUTH_CODE_EXPIRED** — deadline < now
6. **AUTH_CODE_EXHAUSTED** — activated_count >= max_activations
7. 调用 `activateAuthCode`（FOR UPDATE 行锁 + 原子递增 `activated_count`）
8. 创建 `fbs_user_pack` 记录
9. 返回激活结果

### 3.2 响应

**成功**：
```json
{
  "code": 200,
  "msg": "激活成功",
  "data": {
    "packId": 1,
    "packName": "写书助手",
    "expiresAt": "2026-12-31T23:59:59",
    "msg": null
  }
}
```

**幂等（已激活）**：
```json
{
  "code": 200,
  "msg": "已激活该场景包",
  "data": {
    "packId": 1,
    "packName": "写书助手",
    "expiresAt": "2026-12-31T23:59:59",
    "msg": "已激活该场景包"
  }
}
```

**失败（错误码在 msg 字段）**：
```json
{ "code": 400, "msg": "AUTH_CODE_EXPIRED", "data": null }
```

### 3.3 授权码与激活次数

| 字段 | 说明 |
|------|------|
| max_activations | 最大激活次数 |
| activated_count | 已激活次数 |

- max_activations=1：一次性授权码，只能激活一次
- max_activations>1：可多人共用，或同一用户多地激活

## 四、领取平台场景包

**接口**：`POST /my/scene-pack/claim`

**请求体**：`{ "packCode": "pack_bookwriter" }`

### 4.1 可领取判定规则（全部满足）

| 条件 | 字段 | 值 |
|------|------|-----|
| 归属类型 | owner_type | 1（平台包） |
| 上架状态 | status | 1（已发布） |
| 可见性 | visible_scope | ALL（所有人可见） |
| 免费 | points_rule_code | NULL（非 NULL=需付费，暂不支持） |
| 用户未拥有 | — | 用户在 fbs_user_pack 中无该 packId 且 status!=3 的记录 |

### 4.2 业务流程（Fail-Closed 校验链）

1. **幂等检查**：用户是否已有该包有效权益 → 有则返回 `ALREADY_CLAIMED`（HTTP 200）
2. **PACK_NOT_FOUND** — packId 不存在或 del_flag != '0'
3. **PACK_OFFLINE** — status != 1（已发布）
4. **PACK_PRIVATE** — owner_type != 1（企业包走企业路径，禁止个人领取）
5. **PACK_NOT_FREE** — points_rule_code IS NOT NULL（付费包走后续购买流程）
6. 事务写入 `fbs_user_pack` 记录
7. 返回领取结果

### 4.3 响应

**成功**：
```json
{
  "code": 200,
  "msg": "领取成功",
  "data": {
    "packId": 1,
    "packName": "写书助手",
    "expiresAt": null,
    "msg": null
  }
}
```

**幂等（已领取）**：
```json
{
  "code": 200,
  "msg": "已领取该场景包",
  "data": {
    "packId": 1,
    "packName": "写书助手",
    "expiresAt": null,
    "msg": "已领取该场景包"
  }
}
```

## 五、查看可领取场景包

**接口**：`GET /my/scene-packs`

**请求参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| pageNum | int | 否 | 1 | 页码 |
| pageSize | int | 否 | 10 | 每页条数，最大 100 |
| keyword | String | 否 | — | 名称/编码关键字搜索 |

**返回字段**：
| 字段 | 说明 |
|------|------|
| id | 场景包ID |
| packCode | 场景包编码 |
| packName | 场景包名称 |
| currentVersion | 当前版本号 |
| description | 描述 |
| pointsRuleCode | 积分规则编码（NULL=免费） |
| createTime | 创建时间 |
| claimed | 是否已领取（true/false） |

## 六、权益状态说明

### 6.1 fbs_user_pack.status

| 状态值 | 名称 | 说明 |
|--------|------|------|
| 1 | 有效 | 正常使用 |
| 2 | 已过期 | 超过有效期 |
| 3 | 已撤销 | 被系统撤销 |

### 6.2 来源类型 sourceType

| 值 | 名称 | 说明 |
|-----|------|------|
| 1 | 平台分发 | 平台运营人员发放 |
| 2 | 企业分发 | 企业管理员发放 |
| 3 | 用户激活 | 用户通过授权码激活 |
