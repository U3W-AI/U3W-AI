# 授权码管理

本文档说明平台运营侧授权码的功能、生成规则、激活流程和状态管理。

---

## 一、功能概述

授权码（Auth Code）是将场景包权益分发给用户的凭证。用户持有授权码，可以通过用户自助 API 激活获得场景包权益，无需运营人员手动操作。

**核心特性：**
- 授权码内含目标场景包信息（packId），用户激活时无需知道 packCode
- 支持一次性激活（maxActivations=1）或多地激活（maxActivations>1）
- 支持有效期限制（deadline=NULL 表示永不过期）
- 可批量生成（CURD 一次生成多个）

---

## 二、授权码状态机

```
未激活(0) → 已激活(1) → 已用尽(2)
               ↓
           已撤销(4)
```

| 状态值 | 名称 | 说明 |
|--------|------|------|
| 0 | 未激活 | 有效，可被使用 |
| 1 | 已激活 | 已被使用过（activated_count >= 1 但 < max_activations），仍可继续使用 |
| 2 | 已用尽 | activated_count >= max_activations，不可再激活 |
| 4 | 已撤销 | 运营手动撤销，不再可用 |

**可用状态判断**：`status = 0 或 status = 1` 且 `available = 1` 且 `deadline > now` 且 `activated_count < max_activations`

## 三、生成授权码

**接口**：`POST /business/fbs/auth-code/generate`

**请求体**：
```json
{
  "targetPackCode": "pack_bookwriter",
  "count": 10,
  "deadline": "2026-12-31"
}
```

| 参数 | 说明 |
|------|------|
| targetPackCode | 目标场景包编码（与 targetId 二选一） |
| targetId | 目标场景包ID（与 targetPackCode 二选一） |
| count | 生成数量（1-1000） |
| deadline | 有效期截止日期（NULL=永不过期） |

**响应**（返回 `Map<Long, String>`，key=授权码ID，value=授权码）：
```json
{
  "code": 200,
  "data": {
    "1": "FBS-XXXXXXXXXXXX",
    "2": "FBS-YYYYYYYYYYYY"
  }
}
```

**生成规则：**
- 格式：UUID前16位 + 随机4位，共20位
- 字符集：字母数字混合
- 唯一约束：数据库 uk_auth_code 保证不重复

**前置条件：**
- 目标场景包 status=1（已发布），否则返回错误

---

## 四、禁用/启用/撤销

**操作对象**：以上三个接口均以 `id`（授权码主键）为操作对象，使用 `IdRequest` 请求体。

### 4.1 禁用

**接口**：`PUT /business/fbs/auth-code/disable`

**请求体**：`{ "id": 1 }`

**效果**：`available = 0`，授权码不可用（激活时 fail-closed）

### 4.2 启用

**接口**：`PUT /business/fbs/auth-code/enable`

**请求体**：`{ "id": 1 }`

**效果**：`available = 1`，恢复正常可用（前提：未用尽/未过期/未撤销）

### 4.3 撤销

**接口**：`PUT /business/fbs/auth-code/revoke`

**请求体**：`{ "id": 1 }`

**效果**：`status = 4`，永久不可用

## 五、用户激活流程

用户通过授权码激活获得场景包权益：

**接口**：`POST /my/auth-code/activate`

**请求体**：`{ "authCode": "FBS-XXXXXXXXXXXX" }`

**业务流程（Fail-Closed 校验链）：**

1. **AUTH_CODE_INVALID** — 授权码不存在
2. **AUTH_CODE_DISABLED** — available != 1
3. **AUTH_CODE_REVOKED** — status = 4（已撤销）
4. **AUTH_CODE_EXPIRED** — deadline < now
5. **AUTH_CODE_EXHAUSTED** — activated_count >= max_activations

通过全部校验后：
6. 原子递增 `activated_count`（FOR UPDATE 行锁）
7. 创建 `fbs_user_pack` 记录（sourceType=3=用户激活）
8. 返回激活结果

**幂等处理：**
- 激活前先查用户是否已有该包有效权益（status=1）
- 有则返回 `ALREADY_ACTIVATED`（HTTP 200），不再重复激活

**成功响应**：
```json
{
  "code": 200,
  "msg": "激活成功",
  "data": {
    "packId": 1,
    "packName": "写书助手",
    "expiresAt": "2026-12-31T23:59:59",
    "msg": null
  }
}
```

**幂等（已激活）**：
```json
{
  "code": 200,
  "msg": "已激活该场景包",
  "data": {
    "packId": 1,
    "packName": "写书助手",
    "expiresAt": "2026-12-31T23:59:59",
    "msg": "已激活该场景包"
  }
}
```

**失败响应**（错误码在 msg 字段返回）：
```json
{ "code": 400, "msg": "AUTH_CODE_EXPIRED", "data": null }
```

## 六、数据模型

### fbs_auth_code 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| auth_code | VARCHAR(32) | 授权码（唯一） |
| code_type | INT | 类型：1=场景包权益码 |
| target_type | VARCHAR(32) | 目标类型：SCENE_PACK |
| target_id | BIGINT | 目标ID（场景包ID） |
| issuer_type | INT | 发放方类型：1=平台, 2=企业 |
| issuer_id | BIGINT | 发放方ID |
| available | INT | 可用标志：0=禁用, 1=可用 |
| status | INT | 状态：0=未激活, 1=已激活, 2=已用尽, 4=已撤销 |
| deadline | DATETIME | 有效期截止（NULL=永不过期） |
| max_activations | INT | 最大激活次数 |
| activated_count | INT | 已激活次数 |
| del_flag | CHAR(1) | 删除标志 |
