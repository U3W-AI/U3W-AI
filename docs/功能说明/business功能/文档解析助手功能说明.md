## 🎯 功能概述

### 什么是文档解析助手？

**文档解析助手**是一个基于AI大模型的文档智能解析系统，通过集成腾讯元器智能体平台，帮助用户快速提取和分析文档内容，获取关键信息。

### 核心特性

- ✅ **多格式文档支持**  
  支持PDF、Word、TXT、MD等多种格式的文档上传和解析

- ✅ **智能内容提取**  
  使用腾讯元器智能体深度理解文档内容，根据用户提示词提取关键信息

- ✅ **异步处理架构**  
  后台异步调用AI解析，前端轮询获取状态，用户无需等待

- ✅ **URL上传方式**  
  文档上传后生成可访问URL，智能体通过URL读取文档内容

- ✅ **历史记录管理**  
  保存所有解析记录，支持查看、重试和删除

- ✅ **错误重试机制**  
  解析失败时支持一键重试，提高成功率

```java
@PostMapping("/uploadAndParse")
public AjaxResult uploadAndParse(
        @RequestParam("file") MultipartFile file,
        @RequestParam("prompt") String prompt,
        @RequestParam(value = "documentId", required = false) String documentId,
        @RequestParam(value = "documentName", required = false) String documentName,
        HttpServletRequest request) {
    
    // 1. 参数校验
    if (file.isEmpty()) {
        return error("请选择要上传的文档");
    }
    
    if (StringUtils.isEmpty(prompt)) {
        return error("请输入解析提示词");
    }
    
    // 2. 生成documentId（前端生成，后端也可以生成）
    if (StringUtils.isEmpty(documentId)) {
        documentId = "DOC-" + DateUtils.dateTimeNow("yyyyMMddHHmmss") + "-" + 
                     UUID.randomUUID().toString().substring(0, 8).toUpperCase();
    }
    
    // 3. 调用内部 /upload 接口上传文件
    RestTemplate restTemplate = new RestTemplate();
    String uploadUrl = "http://localhost:8080/common/upload";
    
    HttpHeaders uploadHeaders = new HttpHeaders();
    uploadHeaders.setContentType(MediaType.MULTIPART_FORM_DATA);
    
    // 获取当前请求的 Authorization 头并传递给内部调用
    String authorizationHeader = request.getHeader("Authorization");
    if (authorizationHeader != null && !authorizationHeader.isEmpty()) {
        uploadHeaders.set("Authorization", authorizationHeader);
    }
    
    // 构建上传请求体
    LinkedMultiValueMap<String, Object> uploadBody = new LinkedMultiValueMap<>();
    uploadBody.add("file", file.getResource());
    
    HttpEntity<LinkedMultiValueMap<String, Object>> uploadRequest = 
        new HttpEntity<>(uploadBody, uploadHeaders);
    
    @SuppressWarnings("unchecked")
    Map<String, Object> uploadResponse = restTemplate.postForObject(
        uploadUrl, uploadRequest, Map.class
    );
    
    // 4. 提取URL并替换域名
    String url = (String) uploadResponse.get("url");
    String originalFilename = (String) uploadResponse.get("originalFilename");
    
    // 替换域名：localhost:8080 → 内网穿透域名（从配置文件读取）
    String replacedUrl = url.replace("http://localhost:8080", tunnelDomain);
    
    // 5. 获取用户ID
    Long userId = getUserId();
    
    // 6. 快速创建文档解析记录（同步，< 100ms）
    DocumentParse documentParse = documentParseService.createDocumentParseAndProcess(
        userId, documentId, documentName, prompt, null
    );
    
    // 7. 触发异步解析任务（从Controller调用确保@Async生效）
    documentParseService.triggerDocumentParse(
        documentParse.getId(), userId, documentId, prompt, 
        replacedUrl, originalFilename
    );
    
    // 8. 立即返回（不等待AI解析结果）
    Map<String, Object> result = new HashMap<>();
    result.put("id", documentParse.getId());
    result.put("documentId", documentParse.getDocumentId());
    result.put("documentName", documentParse.getDocumentName());
    result.put("processStatus", documentParse.getProcessStatus());
    result.put("message", "文档上传成功，AI解析正在进行中，请稍后查询处理状态");
    
    return success(result);
}
```

```java
@Override
public DocumentParse createDocumentParseAndProcess(Long userId, String documentId, 
                                                    String documentName, String prompt, 
                                                    String base64Content) {
    // 1. 快速创建新文档解析记录
    DocumentParse documentParse = new DocumentParse();
    documentParse.setUserId(userId);
    documentParse.setDocumentId(documentId);
    documentParse.setDocumentName(documentName);
    documentParse.setPrompt(prompt);
    documentParse.setProcessStatus(0); // 处理中
    
    // 2. 立即保存到数据库
    documentParseMapper.insertDocumentParse(documentParse);
    
    log.info("文档解析记录创建成功 - 记录ID: {}, 文档ID: {}, 等待Controller触发异步解析", 
             documentParse.getId(), documentId);
    
    // 3. 返回记录（Controller层会调用异步方法）
    return documentParse;
}

@Async("asyncTaskExecutor")
@Override
public void triggerDocumentParse(Long documentParseId, Long userId, String documentId, 
                                  String prompt, String url, String originalFilename) {
    log.info("[异步任务] 开始处理文档解析 - 记录ID: {}, 文档ID: {}", 
             documentParseId, documentId);
    
    try {
        // 获取用户的腾讯元器智能体配置
        YuanqiAgentConfig config = yuanqiAgentConfigService
            .selectActiveConfigByUserIdDecrypted(userId);
        
        if (config == null) {
            log.error("[异步任务] 未找到智能体配置 - 记录ID: {}", documentParseId);
            updateDocumentParseStatus(documentParseId, 2, 
                "未找到启用的腾讯元器智能体配置", null);
            return;
        }
        
        // 调用腾讯元器智能体API（工作流）
        String appKey = config.getApiKey();     // API密钥（appkey）
        String appId = config.getAgentId();     // 智能体ID（appid）
        String userIdStr = String.valueOf(userId);
        
        log.info("[异步任务] 开始解析文档 - 记录ID: {}, 文档ID: {}", 
                 documentParseId, documentId);
        
        // 调用API服务（异步工作流，只提交任务，不等待内容）
        YuanqiApiResponse response = yuanqiAgentApiService.parseDocument(
            appKey, appId, userIdStr, documentId, prompt, url, originalFilename
        );
        
        if (response.isSuccess()) {
            // 工作流任务已提交成功，记录taskId
            updateDocumentParseStatus(documentParseId, 0, null, response.getTaskId());
            
            // 启动5分钟超时检查
            scheduleCallbackTimeoutCheck(documentParseId, documentId);
        } else {
            updateDocumentParseStatus(documentParseId, 2, 
                response.getErrorMessage(), null);
        }
    } catch (Exception e) {
        log.error("[异步任务] 文档解析异常 - 记录ID: {}", documentParseId, e);
        updateDocumentParseStatus(documentParseId, 2, 
            "文档解析失败: " + e.getMessage(), null);
    }
}
```

### 2. 腾讯元器API调用

**YuanqiAgentApiService.java**

```java
public YuanqiApiResponse parseDocument(String appKey, String appId, String userId, 
                                        String documentId, String prompt, 
                                        String url, String originalFilename) {
    // 构建请求头
    HttpHeaders headers = new HttpHeaders();
    headers.setContentType(MediaType.APPLICATION_JSON);
    headers.set("Authorization", "Bearer " + appKey);
    
    // 构建请求体
    Map<String, Object> requestBody = new HashMap<>();
    requestBody.put("assistant_id", appId);
    requestBody.put("user_id", userId);
    requestBody.put("stream", false);
    
    // 构建消息：发送JSON格式的参数
    List<Map<String, Object>> messages = new ArrayList<>();
    Map<String, Object> userMessage = new HashMap<>();
    userMessage.put("role", "user");
    
    // 消息内容：JSON格式包含所有必要参数
    String jsonMessage = String.format(
        "{\"documentId\":\"%s\",\"prompt\":\"%s\",\"url\":\"%s\",\"originalFilename\":\"%s\"}", 
        documentId, prompt, url, originalFilename
    );
    
    List<Map<String, Object>> contentList = new ArrayList<>();
    Map<String, Object> textContent = new HashMap<>();
    textContent.put("type", "text");
    textContent.put("text", jsonMessage);
    contentList.add(textContent);
    
    userMessage.put("content", contentList);
    messages.add(userMessage);
    requestBody.put("messages", messages);
    
    // 发送请求
    HttpEntity<Map<String, Object>> requestEntity = new HttpEntity<>(requestBody, headers);
    ResponseEntity<String> response = restTemplate.exchange(
        "https://yuanqi.tencent.com/openapi/v1/agent/chat/completions",
        HttpMethod.POST,
        requestEntity,
        String.class
    );
    
    // 解析响应，获取taskId
    return parseResponse(response.getBody());
}
```

### 4. 前端轮询机制

**index.vue**

```javascript
// 轮询单条解析记录的生成状态
const startPollingParse = (parseId, documentId) => {
  let pollCount = 0
  const maxPolls = 60  // 5分钟（60 * 5秒 = 300秒）

  const pollInterval = setInterval(async () => {
    pollCount++

    try {
      // 刷新列表，获取最新的解析内容
      await loadParses()
      const parse = parseList.value.find(p => p.id === parseId)

      if (parse) {
        // 如果当前选中的就是这条记录，自动更新显示最新内容
        if (selectedParse.value && selectedParse.value.id === parseId) {
          selectedParse.value = parse
        }

        // 检查是否完成或失败
        if (parse.processStatus === 1) {
          // 解析完成
          clearInterval(pollInterval)

          ElNotification({
            title: '解析完成',
            message: `文档"${parse.documentName || documentId}"已解析完成！`,
            type: 'success',
            duration: 5000
          })
        } else if (parse.processStatus === 2) {
          // 解析失败
          clearInterval(pollInterval)

          ElNotification({
            title: '解析失败',
            message: `文档"${parse.documentName || documentId}"解析失败：${parse.errorMessage || '未知错误'}`,
            type: 'error',
            duration: 8000
          })
        }
        // status=0 继续轮询

      } else if (pollCount >= maxPolls) {
        // 超时处理（5分钟）
        clearInterval(pollInterval)

        ElNotification({
          title: '解析超时',
          message: `文档"${documentId}"解析超时（超过5分钟），请刷新页面检查解析状态`,
          type: 'warning',
          duration: 0  // 不自动关闭
        })
      }
    } catch (error) {
      console.error('轮询失败:', error)
      // 轮询失败不影响整体流程，继续轮询
    }
  }, 5000)  // 每5秒轮询一次
}
```

## 🔧 腾讯元器工作流配置

### 工作流参数

文档解析智能体工作流需要接收以下参数：

```json
{
  "documentId": "DOC-20251226123456-ABC12345",
  "prompt": "请提取文档中的关键信息",
  "url": "http://内网穿透域名/xxx.pdf",
  "originalFilename": "example.pdf"
}
```

### 工作流流程

1. **参数提取**：从JSON消息中提取 `documentId`、`prompt`、`url`、`originalFilename`

2. **文档读取**：通过 `url` 读取文档内容（支持PDF、Word、TXT等格式）

3. **智能解析**：根据 `prompt` 对文档内容进行智能分析和提取

4. **HTTP回调**：将解析结果通过HTTP回调发送到系统

### HTTP回调配置

### ⚠️ 重要配置：域名配置

在使用文档解析助手之前，**如果使用内网穿透，必须配置域名**，否则腾讯元器智能体无法访问上传的文档。

#### 配置方式一：修改配置文件

1. 打开配置文件：`FBSir-admin/src/main/resources/application.yml`

2. 找到 `fbsir` 配置部分，修改 `domain` 配置项：
   ```yaml
   fbsir:
     # 域名配置（用于拼接完整URL）
     # 开发环境：http://localhost:8080
     # 生产环境/内网穿透：使用实际访问域名（如 http://your-domain.com）
     domain: http://abc.com
   ```

3. 将 `http://abc.com` 替换为您的实际公网访问地址

4. 保存文件并重启后端服务

#### 配置方式二：使用环境变量（推荐生产环境）

设置环境变量 `FBSIR_DOMAIN` 为您的公网访问地址：

**Windows:**
```bash
set FBSIR_DOMAIN=http://abc.com
```

**Linux/Mac:**
```bash
export FBSIR_DOMAIN=http://abc.com
```

#### 为什么需要配置？

- 文档上传后，系统会生成一个访问URL（如 `http://localhost:8080/profile/upload/xxx.pdf`）
- 腾讯元器智能体运行在云端，无法访问本地的 `localhost:8080`
- 系统会自动将 `localhost:8080` 替换为配置的域名，使智能体能够通过公网访问文档
- 如果不配置，智能体将无法读取文档内容，导致解析失败

### ⚙️ 异步任务配置

文档解析助手使用Spring的 `@Async` 注解实现异步处理，需要配置异步任务线程池。

#### 配置文件位置

`FBSir-framework/src/main/java/com/wx/fbsir/framework/config/AsyncConfig.java`

#### 配置示例

```java
@Configuration
@EnableAsync
public class AsyncConfig {
    
    @Bean("asyncTaskExecutor")
    public ThreadPoolTaskExecutor asyncTaskExecutor() {
        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        executor.setCorePoolSize(5);           // 核心线程数
        executor.setMaxPoolSize(10);           // 最大线程数
        executor.setQueueCapacity(200);         // 队列容量
        executor.setThreadNamePrefix("async-"); // 线程名前缀
        executor.initialize();
        return executor;
    }
}
```

#### 注意事项

- 确保配置了名为 `asyncTaskExecutor` 的线程池Bean
- 异步任务在独立线程中执行，不会阻塞主线程
- 线程池大小可根据实际需求调整

## ❓ 常见问题

### 1. 上传文档后提示"未找到智能体配置"怎么办？

**原因**：您还没有配置腾讯元器智能体。

**解决方法**：
1. 点击页面右上角的"配置智能体"按钮
2. 按照以下步骤获取appid和apikey：
   
   **获取appid：**
   - 登录腾讯元器平台
   - 进入"文档解析助手智能体"
   - 点击左侧菜单"应用发布"→"服务状态"
   - 在"体验链接"中截取appid部分
   - 例如：`https://yuanqi.tencent.com/chat/assistant/1234567890abcdef`，appid为`1234567890abcdef`
   
   **获取apikey：**
   - 在"应用发布"页面中，点击"API管理"标签页
   - 找到API密钥（apikey）字段
   - 点击"复制"按钮复制apikey
   
3. 将获取的appid和apikey填入配置表单
4. 保存配置后重新上传文档

### 2. 解析一直显示"处理中"状态？

**原因**：
- AI解析需要一定时间，通常在10-60秒之间
- 网络问题导致回调失败
- 腾讯元器服务异常
- **内网穿透域名未配置或配置错误**（最常见原因）

**解决方法**：
1. 等待5分钟，系统会自动超时并提示
2. 刷新页面查看最新状态
3. 如果超时，点击"重试"按钮重新解析
4. **检查是否已正确配置内网穿透域名**（见上方"重要配置：内网穿透域名"章节）
5. 检查腾讯元器工作流配置是否正确
6. 确认内网穿透服务是否正常运行

### 3. 解析失败，显示错误信息？

**原因**：
- 智能体配置错误
- 文档格式不支持
- 提示词不清晰
- 腾讯元器服务异常
- **内网穿透域名未配置或配置错误，导致智能体无法访问文档**

**解决方法**：
1. 检查智能体配置是否正确
2. 确认文档格式是否支持
3. 优化提示词，使其更清晰明确
4. **检查是否已正确配置内网穿透域名**（见上方"重要配置：内网穿透域名"章节）
5. 确认内网穿透服务是否正常运行
6. 点击"重试"按钮重新解析
7. 联系管理员检查腾讯元器服务状态

### 4. 支持哪些文档格式？

**支持的格式**：
- PDF（.pdf）
- Word（.doc, .docx）
- 纯文本（.txt）
- Markdown（.md）

**不支持**：
- 图片格式（.jpg, .png等）
- 压缩文件（.zip, .rar等）
- 其他非文本格式

### 5. 文档大小有限制吗？

是的，文档大小有限制：
- 默认限制：10MB
- 如需调整，请联系管理员修改系统配置

### 6. 解析记录会保存多久？

解析记录会永久保存在数据库中，除非您手动删除。

### 7. 可以同时解析多个文档吗？

可以，系统支持并发解析多个文档：
- 每个文档解析任务独立执行
- 前端会为每个任务单独轮询状态
- 不影响其他任务的执行

### 8. 如何提高解析准确率？

提高解析准确率的方法：
1. **优化提示词**：使用清晰、具体的提示词
   - ❌ "分析文档"
   - ✅ "请提取文档中的所有联系人姓名、电话和邮箱"

2. **选择合适的文档**：
   - 文档内容清晰、结构化
   - 避免扫描件或图片格式
   - 确保文档格式正确

3. **配置合适的智能体**：
   - 选择针对文档解析优化的智能体
   - 定期更新智能体配置

### 9. 解析结果不准确怎么办？

解决方法：
1. 优化提示词，使其更具体明确
2. 检查文档内容是否清晰
3. 尝试使用不同的提示词重新解析
4. 联系管理员优化智能体配置

### 10. 如何导出解析结果？

当前版本支持：
1. 点击"复制内容"按钮复制到剪贴板
2. 手动粘贴到其他文档中

未来版本将支持：
- 导出为Word文档
- 导出为PDF文档
- 导出为Excel表格
