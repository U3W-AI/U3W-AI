# 消费记录与配额

本文档说明 Skill API 消费（consume/start/end）、企业配额扣减规则、以及使用记录状态机。

---

## 一、消费模式

Skill API 提供两种消费模式：**一次性消费**和**两阶段使用**，两者互斥，同一 usageRecordId 只能走一种模式。

### 1.1 一次性消费（consume）

**接口**：`POST /fbs/skill-api/usage/consume`

**适用场景**：简单场景，调用即完成"校验 → 扣减积分 → 写入使用记录"

**业务流程**：
1. 校验用户权益（userId + packCode）
2. 计算积分扣减（根据 packCode → pointsRuleCode → wx_points_rule.points_value）
3. 扣减积分（IPointsService.changePoints）
4. 幂等写入 fbs_skill_usage_record（status=1 成功结束）

**请求参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 否 | 用户ID（可空，从API Key反查） |
| packCode | String | 是 | 场景包编码 |
| skillCode | String | 是 | 技能编码 |
| usageRecordId | String | 是 | 使用记录ID（幂等键） |
| hostType | String | 否 | 宿主类型，默认WORKBUDDY |
| authCode | String | 否 | 授权码 |

**⚠️ 不传 pointsAmount**：扣减金额由后端自动计算，调用方不能指定。

**幂等语义**：记录已存在且 status=1（成功）→ 幂等返回；status=2（失败）或 status=0（进行中）→ 均拒绝。

**响应示例**：

成功：
```json
{
  "code": 200,
  "data": {
    "success": true,
    "usageRecordId": "wb-task-abc123",
    "remainPoints": 990,
    "failReason": null
  }
}
```

失败（积分不足）：
```json
{
  "code": 200,
  "data": {
    "success": false,
    "usageRecordId": "wb-task-abc123",
    "remainPoints": 5,
    "failReason": "积分余额不足"
  }
}
```

### 1.2 两阶段使用（start + end）

**适用场景**：长会话场景或只需记录不使用积分的场景（如日志记录）。

**接口**：`POST /fbs/skill-api/usage/start`

**业务流程（start）**：
1. 幂等写入 fbs_skill_usage_record（status=0 进行中）
2. 不扣减积分、不扣减配额
3. 返回 usageRecordId + status=0

**接口**：`PUT /fbs/skill-api/usage/end/{usageRecordId}`

**业务流程（end）**：
1. 参数校验：status 必须为 1（成功）或 2（失败），否则返回错误
2. 更新使用记录状态（status=1 成功 或 status=2 失败）
3. 不扣减积分、不扣减配额

**⚠️ 与 consume 互斥**：同一 usageRecordId 只能走一种模式，不能 start → end → consume 组合。

---

## 二、幂等键 usageRecordId

usageRecordId 是全链路的幂等键，类型为 String（非数据库自增 Long）。

**推荐格式**：
- WorkBuddy taskId：`wb-task-{uuid}`
- UUID：`{uuid}`

**幂等语义**：
- start：记录已存在且 status=0 → **幂等返回已有记录**（不重复创建）；status=1/2 → 返回 409
- end：记录已存在且 status=1/2 → 返回 409 冲突
- consume：
  - 记录已存在且 status=1（成功） → 幂等返回
  - 记录已存在且 status=2（失败） → 拒绝，不允许重复提交
  - 记录已存在且 status=0（进行中） → 拒绝，使用记录正在处理中

---

## 三、使用记录状态机

```
进行中(0) → 成功结束(1)
          → 失败结束(2)
```

| 状态值 | 名称 | 说明 |
|--------|------|------|
| 0 | 进行中 | start 后、end 前的中间状态 |
| 1 | 成功结束 | 正常使用完成 |
| 2 | 失败结束 | 使用失败（如积分不足、配额用尽） |

## 四、企业配额扣减规则

### 4.1 配额模型

企业包配额在 fbs_enterprise_pack 层面统一管理：

| 字段 | 说明 |
|------|------|
| packQuota | 配额上限（最大使用次数） |
| usedQuota | 已使用次数 |
| remainQuota | 剩余配额 = packQuota - usedQuota |

### 4.2 配额扣减时机

配额在 consume 成功后扣减（不是 start 时扣减）：

1. consume 开始
2. 综合权益校验（用户授权有效、企业配额充足）
3. 根据 hostType 分流：
   - WORKBUDDY/STANDALONE：综合校验后（场景包权限 + 积分余额），调用 `IPointsService.changePoints` 扣减个人积分（`sys_user.points`）；若 `points_rule_code = NULL`（免费包），跳过积分扣减
   - ENTERPRISE：综合校验后（企业状态 + 成员授权 + 配额充足），只扣减企业配额（`fbs_enterprise_pack.usedQuota++`），不扣个人积分，不 fallback 到个人授权路径
4. consume 成功 → usedQuota++（仅企业路径）

### 4.3 Fail-Closed 校验链

消费时执行以下校验，任一失败则拒绝：

| 校验点 | 失败响应 | 说明 |
|--------|---------|------|
| 用户存在且状态正常 | 用户不可用 | sys_user 状态检查 |
| 用户有该包权益 | 用户未获此包授权 | fbs_user_pack.status = 1 |
| 企业包存在且配额充足 | 企业配额已用尽 | usedQuota >= packQuota |
| 成员授权有效（hostType=ENTERPRISE） | 成员授权已失效 | fbs_member_pack.status = 1 |

### 4.4 配额不足的错误响应

```json
{
  "code": 500,
  "msg": "企业配额已用尽，请联系管理员",
  "data": { "success": false, "failReason": "企业配额已用尽，请联系管理员" }
}
```

## 五、数据模型

### fbs_skill_usage_record 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| usage_record_id | VARCHAR(64) | 使用记录ID（幂等键，唯一） |
| user_id | BIGINT | 用户ID |
| pack_id | BIGINT | 场景包ID |
| pack_version | VARCHAR(32) | 场景包版本 |
| skill_code | VARCHAR(64) | 技能编码 |
| host_type | VARCHAR(32) | 宿主类型：WORKBUDDY/STANDALONE/ENTERPRISE |
| host_session_id | VARCHAR(64) | 宿主会话ID |
| points_amount | INT | 积分变动值 |
| status | INT | 状态：0=进行中, 1=成功结束, 2=失败结束 |
| start_time | DATETIME | 开始时间 |
| end_time | DATETIME | 结束时间 |
| error_message | TEXT | 失败原因 |
| del_flag | CHAR(1) | 删除标志 |

## 六、错误码说明

### consume 错误码

| body.code | 场景 |
|-----------|------|
| 403 | 无法识别用户（API Key 未绑定且未传 userId） |
| 500 | 参数不能为空（packCode/usageRecordId/skillCode 任一为空） |
| 500 | 场景包不存在 |
| 500 | 用户未获此包授权 |
| 500 | 企业配额已用尽 |
| 500 | 积分不足 |

### start 错误码

| body.code | 场景 |
|-----------|------|
| 500 | 参数不能为空（userId/packCode/usageRecordId/skillCode 任一为空） |
| 409 | 使用记录已成功结束（同一 usageRecordId 不能从 start 切换到 consume） |
| 409 | 使用记录已失败结束（同一 usageRecordId 不能从 start 切换到 consume） |
| 500 | 场景包不存在 |

### end 错误码

| body.code | 场景 |
|-----------|------|
| 400 | status 参数缺失或值不为 1/2 |
| 404 | 使用记录不存在 |
| 409 | 使用记录已成功结束（同一 usageRecordId 不能从 start 切换到 end） |
| 409 | 使用记录已失败结束（同一 usageRecordId 不能从 start 切换到 end） |
