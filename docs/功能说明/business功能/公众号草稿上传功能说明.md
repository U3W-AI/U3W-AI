## 📖 功能概述

将日更助手生成的文章自动投递到微信公众号草稿箱，包含以下功能：

- **公众号配置管理** - AppID/AppSecret加密存储
- **图片上传** - 按用户隔离的素材图片管理
- **文章投递** - 支持多种内容类型投递
- **发布记录** - 完整的发布历史记录

## 🗄️ 数据库设计

### 1. 公众号配置表 (wc_office_account)

**表位置：** `sql/wxfbsir.sql`（`wc_office_account` 已并入统一初始化脚本）

存储用户的微信公众号配置信息，包括开发者ID和密钥（加密存储）。

**主要字段：**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | BIGINT | 配置ID（主键） |
| `user_id` | BIGINT | 用户ID（唯一索引） |
| `app_id` | VARCHAR(255) | 开发者ID（AES加密） |
| `app_secret` | VARCHAR(255) | 开发者密钥（AES加密） |
| `office_account_name` | VARCHAR(100) | 公众号名称 |
| `author_name` | VARCHAR(50) | 作者名称 |
| `pic_url` | VARCHAR(500) | 素材封面图URL |
| `media_id` | VARCHAR(100) | 微信素材ID |
| `is_active` | TINYINT | 是否启用（0-禁用，1-启用） |
| `create_time` | DATETIME | 创建时间 |
| `update_time` | DATETIME | 更新时间 |

**特点：**
- 每个用户只能配置一个公众号（通过`user_id`唯一索引约束）
- AppID和AppSecret使用AES-256-GCM加密存储
- 支持启用/禁用状态

**Mapper位置：**
- Java接口：`WcOfficeAccountMapper.java`
- XML映射：`WcOfficeAccountMapper.xml`

### 2. 发布记录表 (wc_office_publish_record)

记录每次文章发布到公众号的详细信息。

**主要字段：**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | BIGINT | 记录ID（主键） |
| `user_id` | BIGINT | 用户ID |
| `article_id` | BIGINT | 关联的日更助手文章ID |
| `office_account_id` | BIGINT | 公众号配置ID |
| `article_title` | VARCHAR(200) | 文章标题 |
| `content_type` | VARCHAR(20) | 发布的内容类型 |
| `publish_status` | TINYINT | 发布状态（0-发布中，1-成功，2-失败） |
| `media_id` | VARCHAR(100) | 微信素材ID |
| `error_message` | TEXT | 失败原因 |
| `publish_time` | DATETIME | 发布时间 |
| `create_time` | DATETIME | 创建时间 |

**内容类型(content_type)：**
- `optimized` - 优化后内容
- `model1` - 模型1生成内容
- `model2` - 模型2生成内容
- `model3` - 模型3生成内容
- `layout` - 排版后内容

**特点：**
- 完整记录每次发布操作
- 支持失败原因记录，便于问题排查
- 通过`article_id`关联日更助手文章
- 记录微信返回的`media_id`，便于后续操作

**Mapper位置：**
- Java接口：`WcOfficePublishRecordMapper.java`
- XML映射：`WcOfficePublishRecordMapper.xml`

### 图片上传后端实现

**代码位置：** `FBSir-common/src/main/java/com/wx/fbsir/common/utils/file/FileUploadUtils.java`

#### 1. 文件名生成方法

```java
/**
 * 公众号专用文件名(用户ID目录 + 原文件名 + 后缀)
 * 如果文件名重复，自动添加序号
 */
public static String officialAccountFilename(MultipartFile file, Long userId, String baseDir) {
    String originalFilename = file.getOriginalFilename();
    String baseName = FilenameUtils.getBaseName(originalFilename);
    String extension = getExtension(file);
    
    // 构建用户目录路径
    String userDir = String.valueOf(userId);
    String fileName = StringUtils.format("{}.{}", baseName, extension);
    
    // 检查文件是否存在，如果存在则添加序号
    File targetFile = new File(baseDir + File.separator + userDir + File.separator + fileName);
    int counter = 1;
    while (targetFile.exists()) {
        fileName = StringUtils.format("{}({}).{}", baseName, counter, extension);
        targetFile = new File(baseDir + File.separator + userDir + File.separator + fileName);
        counter++;
    }
    
    return StringUtils.format("{}/{}", userDir, fileName);
}
```

#### 2. 上传方法

```java
/**
 * 公众号专用上传方法并返回完整URL
 * 使用用户ID作为目录，文件名重复时自动添加序号
 */
public static String uploadOfficialAccountAndGetFullUrl(
    String baseDir, 
    MultipartFile file, 
    Long userId, 
    String[] allowedExtension
) throws FileSizeLimitExceededException, IOException, 
         FileNameLengthLimitExceededException, InvalidExtensionException {
    
    // 文件名长度验证
    int fileNameLength = Objects.requireNonNull(file.getOriginalFilename()).length();
    if (fileNameLength > FileUploadUtils.DEFAULT_FILE_NAME_LENGTH) {
        throw new FileNameLengthLimitExceededException(FileUploadUtils.DEFAULT_FILE_NAME_LENGTH);
    }

    // 文件类型和大小验证
    assertAllowed(file, allowedExtension);

    // 使用公众号专用的文件名生成方法
    String fileName = officialAccountFilename(file, userId, baseDir);

    // 保存文件
    String absPath = getAbsoluteFile(baseDir, fileName).getAbsolutePath();
    file.transferTo(Paths.get(absPath));
    
    // 返回完整URL
    return getFullUrl(baseDir, fileName);
}
```

```java
/**
 * 公众号图片上传请求
 * 上传到 officialaccount/{userId} 目录，并返回完整URL
 * 文件名重复时自动添加序号
 */
@PostMapping("/upload/officialaccount")
public AjaxResult uploadOfficialAccountImage(MultipartFile file) throws Exception {
    try {
        // 获取当前用户ID
        Long userId = getUserId();
        
        // 公众号图片上传路径
        String filePath = FBSirConfig.getOfficialAccountUploadPath();
        
        // 使用公众号专用上传方法
        String fullUrl = FileUploadUtils.uploadOfficialAccountAndGetFullUrl(
            filePath, 
            file, 
            userId, 
            MimeTypeUtils.IMAGE_EXTENSION
        );
        
        AjaxResult ajax = AjaxResult.success();
        ajax.put("url", fullUrl);
        ajax.put("fileName", fullUrl);
        ajax.put("newFileName", FileUtils.getName(fullUrl));
        ajax.put("originalFilename", file.getOriginalFilename());
        return ajax;
    } catch (Exception e) {
        return AjaxResult.error(e.getMessage());
    }
}
```

```java
public String getAccessToken(WcOfficeAccount account) throws Exception {
```

#### 发布流程

**代码位置：** `WcOfficeAccountController.java` → `publishToWechat()`

```java
@PostMapping("/publish")
public AjaxResult publishToWechat(@RequestBody Map<String, Object> body) {
    Long articleId = Long.valueOf(body.get("articleId").toString());
    String contentType = body.get("contentType").toString();
    
    // 1. 验证用户公众号配置
    WcOfficeAccount account = wcOfficeAccountService.getMyOfficeAccount();
    if (account == null || account.getIsActive() == 0) {
        return error("请先配置公众号信息");
    }
    
    // 2. 查询文章内容
    DailyArticle article = dailyArticleService.selectDailyArticleById(articleId);
    String content = getContentByType(article, contentType);
    
    // 3. 创建发布记录
    WcOfficePublishRecord record = new WcOfficePublishRecord();
    record.setArticleId(articleId);
    record.setContentType(contentType);
    record.setPublishStatus(0); // 发布中
    wcOfficePublishRecordService.insertWcOfficePublishRecord(record);
    
    try {
        // 4. 调用微信API
        String mediaId = wechatOfficialApiService.publishToWechat(
            account, article.getTitle(), content
        );
        
        // 5. 更新发布状态和文章发布次数
        record.setPublishStatus(1); // 成功
        record.setMediaId(mediaId);
        wcOfficePublishRecordService.updateWcOfficePublishRecord(record);
        
        // 更新文章发布次数
        article.setPublishCount(article.getPublishCount() + 1);
        dailyArticleService.updateDailyArticle(article);
        
        return success("投递成功");
    } catch (Exception e) {
        // 更新失败状态
        record.setPublishStatus(2); // 失败
        record.setErrorMessage(e.getMessage());
        wcOfficePublishRecordService.updateWcOfficePublishRecord(record);
        return error("投递失败: " + e.getMessage());
    }
}
```

## 🔒 安全性考虑

### 1. 路径安全

- ✅ 用户ID从登录信息获取，无法伪造
- ✅ 不接受前端传递的用户ID
- ✅ 自动创建用户目录，避免路径遍历

**代码位置：** `CommonController.java` → `uploadOfficialAccountImage()`

---

### 2. 文件验证

- ✅ 严格限制文件类型（仅图片）
- ✅ 限制文件大小（5MB）
- ✅ 验证文件名长度（100字符）

**代码位置：** `FileUploadUtils.java` → `assertAllowed()`

---

### 3. 权限控制

- ✅ 需要登录才能上传
- ✅ 只能访问自己的文件
- ✅ 使用 `@PreAuthorize` 控制接口访问

**权限标识：**
- 配置管理：`business:office:config`
- 文章发布：`business:daily:publish`

---

### 4. 敏感信息保护

- ✅ AppID和AppSecret使用AES-256-GCM加密存储
- ✅ 前端返回配置时不包含明文密钥
- ✅ 每次加密使用随机IV
- ✅ 提供认证标签防止篡改

**代码位置：** `AesEncryptUtils.java`
