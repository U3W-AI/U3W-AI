## 文档事实优先级

发生不一致时，按以下顺序判断：

1. 当前源码、构建文件、配置校验器和数据库迁移脚本
2. 根目录[部署文档](../部署文档.md)
3. 当前日期较新的专项功能文档
4. 历史说明和示例截图

数据库固定初始化顺序以 `scripts/init-database.ps1` 为准。外部第三方平台的界面、配额和接口可能变化，应以其官方当前文档为准。

## 公开内容边界

GitHub 公开文档只包含用户可复现的安装、配置、接口和功能说明。以下内容不应进入公开仓库：

- 内部实施总纲、路线图、进度计划和任务看板
- FBS 工程编排合同、复盘过程和开发工具内部说明
- 客户数据、登录态、浏览器存储状态、真实 Webhook 地址和第三方凭据
- 未脱敏的测试证据、生产日志和内部商业分析

公开文档中的示例必须使用占位符，不得提供真实密码、令牌或默认登录密码。若专项文档仍有历史命令，应先按当前源码核验再执行。
