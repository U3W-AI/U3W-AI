# 服务器部署文档（以福帮手项目为例）

## 后端部署

**后端代码打包：**在拉取并测试最新代码后删除对于WxFbsir-admin包下的yml配置文件中的环境变量配置的默认值删除（服务器采用的是从fbsir.env中配置环境变量），然后进行打包操作。

**原jar包备份并上传新jar包：**将原WxFbsir-admin-old.jar删除，原WxFbsir-admin.jar重命名为WxFbsir-admin-old.jar，然后上传新打包完成的WxFbsir-admin.jar。

**环境变量管理（若修改）：**若新提交新增或修改了WxFbsir-admin包下的yml配置文件中的环境变量，对应的新增或修改服务器的bsir.env文件。

**重启项目并测试：**重启以更新项目并进行功能测试，主要针对新增或者修改的功能模块。

**若测试发现问题：**恢复备份和环境变量至原版本。

## 前端部署

**前端代码打包：**在拉取并测试最新代码后删除对于WxFbsir-ui/.env.production文件中的VITE_APP_BASE_API修改成 https://wx.fbsir.com/fbsir ，然后进行打包操作。

**原dist文件夹备份并上传新dist文件夹：**将原dist文件夹备份，然后上传新打包完成的dist文件夹中的文件至原dist文件夹中替换原文件。

**重启项目并测试：**重启以更新项目并进行功能测试，主要针对新增或者修改的功能模块。

**若测试发现问题：**恢复备份至原版本。

## 数据库更新

**本地测试：**在拉取最新代码后，更新本地数据库，然后进行测试。

**备份并更新服务器数据库：**备份原数据库后更新数据库。
**测试：**在服务器进行更新后的数据库测试。

**若测试发现问题：**恢复备份至原版本。
