# 企业微信机器人配置说明

## 项目概述
福帮手（WxFbsir）系统提供了企业微信机器人集成功能，通过 `/api/wechat` 接口处理企业微信的回调消息。本说明将指导您如何正确配置企业微信机器人。

## 接口信息
- **接口路径**: `/api/wechat`
- **控制器**: `WechatBotController.java`
- **功能**: 
  - 处理企业微信URL验证（GET请求）
  - 处理企业微信消息回调（POST请求）
- **部署后访问地址**: `https://wx.fbsir.com//fbsir/api/wechat`

## 配置项说明

在 `application.yml` 文件中，需要配置以下企业微信相关参数：

```yaml
wechat:
  # 企业微信机器人Token（生产环境建议使用环境变量：WECHAT_TOKEN）
  token: ${WECHAT_TOKEN:}
  # 企业微信机器人AES密钥（生产环境建议使用环境变量：WECHAT_AES_KEY）
  aes-key: ${WECHAT_AES_KEY:}
  # 企业微信CorpID（生产环境建议使用环境变量：WECHAT_CORP_ID）
  corp-id: ${WECHAT_CORP_ID:}
```

## 配置步骤

### 1. 企业微信后台配置
在企业微信管理后台进行以下配置：

1. 登录企业微信管理后台
2. 进入"应用管理" → "创建应用"（或选择已有应用）
3. 在应用详情页面，找到"接收消息"配置区域
4. 点击"设置API接收"
5. 填写以下信息：
   - **URL**: `https://wx.fbsir.com//fbsir/api/wechat` （替换为您的实际部署地址）
   - **Token**: 任意设置一个Token值（如：`my_wechat_token`）
   - **EncodingAESKey**: 点击随机生成或自定义一个AES密钥

### 2. 服务器配置
将第1步中设置的值配置到服务器：

#### 方法一：环境变量配置（推荐）
在部署服务器上设置以下环境变量：

```bash
export WECHAT_TOKEN=您在企业微信后台设置的Token值
export WECHAT_AES_KEY=您在企业微信后台设置的EncodingAESKey值
export WECHAT_CORP_ID=您的企业微信CorpID值
```

#### 方法二：直接修改配置文件
修改 `WxFbsir-admin/src/main/resources/application.yml` 文件：

```yaml
wechat:
  token: "您在企业微信后台设置的Token值"
  aes-key: "您在企业微信后台设置的EncodingAESKey值"
  corp-id: "您的企业微信CorpID值"
```

### 3. 重启应用
配置完成后，重启您的应用使配置生效。

## 企业微信后台验证流程

1. 在企业微信后台填写完回调信息后，点击"保存"
2. 企业微信服务器会向您的服务器发送GET请求进行验证
3. 请求路径：`GET /api/wechat`
4. 参数：`msg_signature`、`timestamp`、`nonce`、`echostr`
5. 您的应用将使用配置的Token和AESKey进行验证，并返回 `echostr` 的验证结果
6. 如果验证成功，企业微信后台会显示"验证成功"

## 业务功能

该企业微信机器人支持以下功能：
1. **今日面试**: 发送 "今日面试" 获取当日面试信息
2. **查看历史**: 发送 "查看最近 N" (N为数字) 获取最近的N条记录
3. **菜单提示**: 发送其他消息获取可用的指令菜单

## 常见问题解决

### 问题1：URL验证失败
**可能原因**：
- Token或AESKey配置不正确
- 服务器无法访问
- 配置项缺失

**解决方案**：
1. 确认 `wechat.token`、`wechat.aes-key`、`wechat.corp-id` 配置正确
2. 确认服务器 `https://wx.fbsir.com//fbsir/api/wechat` 可以正常访问
3. 检查防火墙设置，确保端口开放

### 问题2：消息回调失败
**可能原因**：
- 配置项与企业微信后台设置不一致
- 服务器时间偏差过大

**解决方案**：
1. 确认企业微信后台配置的Token和AESKey与服务器配置完全一致
2. 检查服务器时间是否准确

### 问题3：HTTPS要求
**注意**：企业微信在生产环境通常要求使用HTTPS协议，如果您的服务器只支持HTTP，可能会有问题。

## 安全建议

### 1. 环境变量配置
强烈建议使用环境变量而非硬编码配置：

```bash
# 在服务器环境变量中设置
export WECHAT_TOKEN="您的Token值"
export WECHAT_AES_KEY="您的AESKey值" 
export WECHAT_CORP_ID="您的CorpID值"
```

### 2. HTTPS配置
如果可能，建议配置HTTPS以满足企业微信的安全要求。

### 3. 访问控制
考虑添加IP白名单或访问频率限制，防止恶意请求。
