## 后端部署

**后端代码打包：**在拉取并测试最新代码后，按服务器环境变量文件覆盖 `WxFbsir-admin` 配置；不要把密钥提交到仓库，然后进行打包操作。

**原jar包备份并上传新jar包：**将原WxFbsir-admin-old.jar删除，原WxFbsir-admin.jar重命名为WxFbsir-admin-old.jar，然后上传新打包完成的WxFbsir-admin.jar。

**环境变量管理（若修改）：**若新提交新增或修改了 `WxFbsir-admin` 包下的 yml 配置中的环境变量，对应新增或修改服务器的 `fbsir.env` 文件。

**重启项目并测试：**重启以更新项目并进行功能测试，主要针对新增或者修改的功能模块。

**若测试发现问题：**恢复备份和环境变量至原版本。

## 前端部署

**前端代码打包：**生产构建以 `WxFbsir-ui/.env.production` 的 `/prod-api` 为 API 前缀；若生产网关使用完整 URL，必须同步配置同源 WebSocket 代理和路径，不要改成与源码路由不一致的 `/fbsir` 前缀。构建前可用 `VITE_APP_PROXY_TARGET` 做本地验收：

```powershell
$env:VITE_APP_PROXY_TARGET = 'http://127.0.0.1:18080'
npm.cmd run build:prod
```

**原dist文件夹备份并上传新dist文件夹：**将原dist文件夹备份，然后上传新打包完成的dist文件夹中的文件至原dist文件夹中替换原文件。

**重启项目并测试：**重启以更新项目并进行功能测试，主要针对新增或者修改的功能模块。

**若测试发现问题：**恢复备份至原版本。

## 数据库更新

**本地测试：**在拉取最新代码后，更新本地数据库，然后进行测试。

**备份并更新服务器数据库：**备份原数据库后更新数据库。
**测试：**在服务器进行更新后的数据库测试。

**若测试发现问题：**恢复备份至原版本。
