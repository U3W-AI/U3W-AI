# 福帮手项目完整服务器部署文档

## 项目概述

福帮手（WxFbsir）是一个面向企业团队与内容运营场景的AI工具链与智能协同平台，采用前后端分离架构，包含主节点（Admin）和副节点（Engine）两部分。

- **WxFbsir-admin**: 主节点，负责业务逻辑、数据管理、用户权限等
- **WxFbsir-ui**: 前端项目，基于Vue 3 + Element Plus构建
- **WxFbsir-engine**: 副节点，负责浏览器自动化、AI任务执行等

---

## 部署环境准备

### 服务器要求
- 操作系统：Linux (Ubuntu 20.04+/CentOS 7+)
- 内存：至少8GB（推荐16GB）
- 硬盘：至少20GB可用空间
- CPU：4核及以上

### 软件依赖
- JDK 17+ (推荐OpenJDK 17)
- Maven 3.8+
- Node.js 18+ (推荐LTS)
- npm 9+ 或 pnpm 8+
- MySQL 8.0+
- Redis 6.0+ (可选)
- 宝塔面板 7.8+

## 后端项目部署 (WxFbsir-admin)

### 1. 项目打包
在本地或CI/CD环境中执行：

```
cd WxFbsir-admin
mvn clean package -DskipTests
```

生成的JAR包位置：`target/wxfbsir-admin-[version].jar`

### 2. 上传JAR包到服务器
将打包好的JAR包上传到服务器指定目录，例如：
```
/home/www/wxfbsir/admin/wxfbsir-admin.jar
```

### 3. 配置环境变量
创建环境配置文件 `/home/www/wxfbsir/admin/fbsir.env`：
```
# 数据库配置
WXFBSIR_MYSQL_URL=jdbc:mysql://localhost:3306/wxfbsir?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=true&serverTimezone=GMT%2B8&allowMultiQueries=true
WXFBSIR_MYSQL_USERNAME=your_username
WXFBSIR_MYSQL_PASSWORD=your_password

# Redis配置（如果使用）
WXFBSIR_REDIS_HOST=localhost
WXFBSIR_REDIS_PORT=6379
WXFBSIR_REDIS_PASSWORD=your_redis_password
WXFBSIR_AES_SECRET_KEY=your_key
WXFBSIR_REDIS_DATABASE=0	

# 文件上传路径
WXFBSIR_FILE_PATH=/home/www/wxfbsir/upload

# value值随便配置仅如此程序也可以运行
WXFBSIR_TOKEN_SECRET=your_token
WXFBSIR_DRUID_USERNAME=your_druid_username
WXFBSIR_DRUID_PASSWORD=your_druid_pass

# Gitee OAuth配置（如果使用）
GITEE_OAUTH_CLIENT_ID=your_gitee_client_id
GITEE_OAUTH_CLIENT_SECRET=your_gitee_client_secret
GITEE_OAUTH_CALLBACK_URL=http://your_domain/auth
GITEE_OAUTH_FRONTEND_URL=http://your_domain

# 域名配置
WXFBSIR_DOMAIN=http://your_domain

#其他需要的配置
#自行添加
```

### 4. 创建系统服务
创建系统服务文件 `/etc/systemd/system/wxfbsir-admin.service`：

```
[Unit]
Description=WxFbsir Admin Service
After=network.target

[Service]
Type=simple
User=www
Group=www
WorkingDirectory=/home/www/wxfbsir/admin
# ExecStart /usr/bin/java替换成自己的 JDK 路径
ExecStart=/usr/bin/java -jar -Xms512m -Xmx2048m /home/www/wxfbsir/admin/wxfbsir-admin.jar
EnvironmentFile=/home/www/wxfbsir/admin/fbsir.env
SuccessExitStatus=143
TimeoutStopSec=10
Restart=on-failure
RestartSec=30

[Install]
WantedBy=multi-user.target
```

### 5. 启动服务
```
# 重新加载systemd配置
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start wxfbsir-admin

# 设置开机自启
sudo systemctl enable wxfbsir-admin

# 查看服务状态
sudo systemctl status wxfbsir-admin

# 查看服务日志
sudo journalctl -u wxfbsir-admin -f
```

## Engine副节点部署 (WxFbsir-engine)

### 1. 项目打包
在本地或CI/CD环境中执行：

```
cd WxFbsir-engine
mvn clean package -DskipTests
```

生成的JAR包位置：`target/wxfbsir-engine-[version].jar`


### 2. 配置Engine
创建Engine配置文件 `/home/www/wxfbsir/engine/application.yml`：
```
server:
  port: 8081

wxfbsir:
  engine:
    # 主节点WebSocket连接地址（请替换为实际的主节点地址）
    ws-url: ws://your_admin_server_ip:8080/ws/engine
    # 主机ID（必须在Admin数据库的白名单中）
    host-id: engine-001
    # 节点版本
    version: "1.0.0"
    
    # 连接配置
    connection:
      # 连接超时时间（毫秒）
      timeout: 30000
      # 心跳间隔（毫秒）
      heartbeat-interval: 30000
      # 心跳超时时间（毫秒）
      heartbeat-timeout: 90000
    
    # 重连配置
    reconnect:
      # 是否启用自动重连
      enabled: true
      # 最大重连次数
      max-attempts: 10
      # 重连间隔（毫秒）
      interval: 5000
      # 重连间隔增量（毫秒）
      interval-increment: 1000
      # 最大重连间隔（毫秒）
      max-interval: 60000
    
    # Playwright浏览器自动化配置
    playwright:
      # 是否启用Playwright
      enabled: true
      # 浏览器数据目录
      data-dir: /home/www/wxfbsir/engine/playwright-data
      # 是否无头模式运行（生产环境建议true）
      headless: true
      
      # 浏览器实例池配置
      instance-pool:
        # 实例池大小，设置为0时自动根据CPU核心数计算
        size: 0
      
      # 浏览器池配置
      pool:
        # 最大并发浏览器实例数，设置为0时启用动态计算
        max-size: 0
        # 最小空件实例数（预热）
        min-idle: 0
        # 会话超时时间（毫秒，默认1小时）
        session-timeout: 3600000
        # 过期会话清理检查间隔（毫秒，默认5分钟）
        cleanup-interval: 300000
        # 获取会话等待超时（毫秒，默认30秒）
        acquire-timeout: 30000
      
      # 浏览器启动配置
      browser:
        # 浏览器启动超时（毫秒，默认60秒）
        launch-timeout: 60000
        # 页面导航超时（毫秒，默认30秒）
        navigation-timeout: 30000
        # 视口宽度（像素）
        viewport-width: 1280
        # 视口高度（像素）
        viewport-height: 720
        # 是否禁用图片加载（减少资源消耗，低性能系统自动启用）
        disable-images: false
        # 是否禁用GPU加速（建议保持true以提高稳定性）
        disable-gpu: true
        # 启动失败最大重试次数
        max-retries: 3
        # 重试间隔基础时间（毫秒，实际等待=重试次数*此值）
        retry-interval: 2000
      
      # 线程池配置
      thread-pool:
        # 核心线程数（设置为0时根据CPU核心数自动计算）
        core-size: 0
        # 最大线程数（设置为0时根据CPU核心数自动计算）
        max-size: 0
        # 线程空闲时间（秒）
        keep-alive-seconds: 60
        # 任务队列大小（设置为0时根据浏览器池大小自动计算）
        queue-capacity: 0

# 日志配置
logging:
  level:
    root: INFO
    com.wx.fbsir.engine: INFO
  pattern:
    console: "%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level [%logger{36}] - %msg%n"
  file:
    name: /home/www/wxfbsir/engine/logs/engine.log
  logback:
    rollingpolicy:
      max-file-size: 50MB
      max-history: 30

# Actuator健康检查配置
management:
  endpoints:
    web:
      exposure:
        include: health,info,metrics
  endpoint:
    health:
      show-details: always
  health:
    defaults:
      enabled: true
```


### 3. 上传JAR包到服务器
将打包好的JAR包上传到服务器指定目录，例如：
```
/home/www/wxfbsir/engine/wxfbsir-engine.jar
```

### 4. 安装Playwright浏览器
```
# 安装Playwright依赖
cd /home/www/wxfbsir/engine
java -jar wxfbsir-engine.jar --version

# 或者直接运行安装命令
# 仅适用于Debian/Ubuntu 系列操作系统
# 其他 Linux：先手动装系统依赖 → 再 npx playwright install chromium
npx playwright install --with-deps chromium
```

### 5. 创建Engine系统服务
创建系统服务文件 `/etc/systemd/system/wxfbsir-engine.service`：
```
[Unit]
Description=WxFbsir Engine Service
After=network.target

[Service]
Type=simple
User=www
Group=www
WorkingDirectory=/home/www/wxfbsir/engine
# ExecStart /www/server/java/jdk-17.0.8/bin/java替换成自己的 JDK 路径
ExecStart=/usr/bin/xvfb-run -a --server-args="-screen 0 1280x1024x24" /www/server/java/jdk-17.0.8/bin/java -jar -Xms512m -Xmx2048m /home/www/wxfbsir/engine/wxfbsir-engine-1.2.6.jar --spring.config.location=file:/home/www/wxfbsir/engine/application.yml
SuccessExitStatus=143
TimeoutStopSec=10
Restart=on-failure
RestartSec=30

[Install]
WantedBy=multi-user.target
```

### 6. 启动Engine服务
```
# 重新加载systemd配置
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start wxfbsir-engine

# 设置开机自启
sudo systemctl enable wxfbsir-engine

# 查看服务状态
sudo systemctl status wxfbsir-engine

# 查看服务日志
sudo journalctl -u wxfbsir-engine -f
```

### 3. 上传构建文件到服务器

```
/home/www/wxfbsir/front/dist/*
```

### 4. 配置Nginx
在宝塔面板中创建网站，或直接编辑Nginx配置文件。注意：配置宝塔面板中的前端配置会覆盖自己直接编辑的Nginx配置，建议直接使用宝塔面板前端配置

直接编辑Nginx配置文件：

创建 `/www/server/panel/vhost/nginx/wxfbsir.conf`：
```
server {
    listen 80;
    listen 443 ssl http2;
    server_name your_domain.com;
    
    # SSL证书配置（如果使用HTTPS）
    ssl_certificate /path/to/your/certificate.crt;
    ssl_certificate_key /path/to/your/private.key;
    
    # 前端静态文件
    location / {
        alias /home/www/wxfbsir/front/dist/;
        try_files $uri $uri/ /index.html;
        expires 1h;
        add_header Cache-Control "public, immutable";
    }
    
    # API代理到后端
    location /fbsir/ {
        proxy_pass http://127.0.0.1:8080/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 30s;
        proxy_send_timeout 30s;
        proxy_read_timeout 30s;
    }
    
    # 上传文件代理
    location /profile/ {
        proxy_pass http://127.0.0.1:8080/profile/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    
    # Gzip压缩
    gzip on;
    gzip_vary on;
    gzip_min_length 1k;
    gzip_comp_level 6;
    gzip_types text/plain application/javascript application/x-javascript text/css application/xml text/javascript application/x-httpd-php image/jpeg image/gif image/png;
    gzip_disable "MSIE [1-6]\.";
    
    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header X-Content-Type-Options "nosniff" always;
}
```

宝塔面板网站THML项目设置中的前端配置文件：

    server {
        listen 80;
        listen 443 ssl ;
        listen [::]:443 ssl ;
        http2 on;
        listen [::]:80;
        server_name your_domain;
    
        # SSL 证书（保留原有）
        ssl_certificate    /www/server/panel/vhost/cert/your_domain/fullchain.pem;
        ssl_certificate_key    /www/server/panel/vhost/cert/your_domain/privkey.pem;
        ssl_protocols TLSv1.1 TLSv1.2 TLSv1.3;
        ssl_ciphers EECDH+CHACHA20:EECDH+CHACHA20-draft:EECDH+AES128:RSA+AES128:EECDH+AES256:RSA+AES256:EECDH+3DES:RSA+3DES:!MD5;
        ssl_prefer_server_ciphers on;
        ssl_session_tickets on;
        ssl_session_cache shared:SSL:10m;
        ssl_session_timeout 10m;
        add_header Strict-Transport-Security "max-age=31536000";
        add_header Alt-Svc 'quic=":443"; h3=":443"; h3-29=":443"; h3-27=":443";h3-25=":443"; h3-T050=":443"; h3-Q050=":443";h3-Q049=":443";h3-Q048=":443"; h3-Q046=":443"; h3-Q043=":443"';
        error_page 497  https://$host$request_uri;
    
        # 强制 HTTPS 重定向（原有，保留）
        set $isRedcert 1;
        if ($server_port != 443) {
            set $isRedcert 2;
        }
        if ( $uri ~ /\.well-known/ ) {
            set $isRedcert 1;
        }
        if ($isRedcert != 1) {
            rewrite ^(/.*)$ https://$host$1 permanent;
        }
    
        # 前端静态文件根目录（请根据实际位置修改）
        root /home/www/wxfbsir/front/dist;
    
        index index.html;
    
        # 关键：处理 Vue 单页应用路由
        location / {
            try_files $uri $uri/ /index.html;
            expires 1h;
            add_header Cache-Control "public, immutable";
        }
    
        # API 代理到 Admin 后端（端口 8080）
        location /fbsir/ {
            proxy_pass http://127.0.0.1:8080/;
            proxy_http_version 1.1;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection "upgrade";
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_connect_timeout 30s;
            proxy_send_timeout 30s;
            proxy_read_timeout 90s;
        }

## 防火墙配置

### 1. 开放必要端口
在服务器安全组和系统防火墙中开放以下端口：
- `80` (HTTP)
- `443` (HTTPS)
- `8080` (Admin后端，如不通过Nginx代理则需要)
- `9090` (Engine服务，如需要外部访问)

### 2. CentOS/RHEL防火墙配置
```
sudo firewall-cmd --permanent --add-port=80/tcp
sudo firewall-cmd --permanent --add-port=443/tcp
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --permanent --add-port=9090/tcp
sudo firewall-cmd --reload
```

### 3. Ubuntu/Debian防火墙配置
```
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 8080/tcp
sudo ufw allow 9090/tcp
sudo ufw reload
```

## 故障排查

### 1. Admin服务启动失败
- 检查数据库连接是否正常
- 检查端口是否被占用
- 查看日志文件中的错误信息

### 2. Engine连接Admin失败
- 检查网络连通性
- 检查WebSocket地址配置
- 检查主机ID是否在白名单中
- 检查防火墙设置

### 3. 前端访问异常
- 检查Nginx配置
- 检查API代理设置
- 检查SSL证书配置

### 4. Playwright浏览器启动失败

- 检查系统依赖是否安装完整
- 检查文件权限
- 检查内存是否充足

### 5.WebSocket连接失败

- 检查前端配置是否添加WebSocket支持
- 检查文件权限
- 检查SSL证书配置

### 6.登录管理器显示：登录失败：未知错误

- 检查engine配置中的线程池数量是否过低
- 检查日志开头有 `xvfb-run` 字样，确保 xvfb 正常运行，程序需要图形渲染

- 检查浏览器缓存是否超载
