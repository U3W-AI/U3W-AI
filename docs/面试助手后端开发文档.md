## 📝 项目简介

面试助手是一个基于企业微信智能机器人协议开发的后端服务。它允许用户通过企业微信群聊或单聊发送指令，快速查询面试候选人的记录。

主要功能包括：
- **消息回调处理**：验证企业微信签名并解密消息。
- **指令识别**：支持 "今日面试" 和 "查看最近 N" 指令。
- **隐私保护**：自动对输出的手机号和身份证进行脱敏处理。
- **持久化存储**：使用 MySQL + MyBatis 管理面试数据。

## 🏗️ 核心架构

### 1. 代码层级结构

本项目遵循标准的 Spring Boot 分层架构，严格遵守 `WxFbsir-business` 模块划分规范。

```text
com.wx.fbsir.business/
├── controller/      # 控制层：处理 HTTP 请求 (WechatBotController)
├── service/         # 业务层：指令解析与数据查询 (InterviewService)
├── mapper/          # 持久层：MyBatis 接口 (InterviewMapper)
├── domain/          # 实体层：数据对象与脱敏逻辑 (InterviewRecord)
├── utils/           # 工具层：加解密工具 (WXBizJsonMsgCrypt)
└── InterviewApplication.java # 启动类
```

### 2. 数据流转图

Plaintext

```
用户发送消息 -> 企业微信服务器 -> /api/wechat (POST)
       -> WechatBotController (验证签名)
       -> WXBizJsonMsgCrypt (解密 JSON)
       -> 指令清洗 (去除 @机器人)
       -> InterviewService (业务查询)
       -> InterviewMapper (SQL 查询)
       -> InterviewRecord (数据脱敏)
       -> WXBizJsonMsgCrypt (加密回复)
       -> 返回企业微信 -> 用户收到回复
```

## 🧩 模块详细说明

### 1. 消息加解密 (Utils)

核心类：`com.wx.fbsir.business.utils.WXBizJsonMsgCrypt`

该类复刻自企业微信官方 Python Demo，负责处理 JSON 协议的加解密。

**关键特性**：

- 使用 Java 原生 `java.util.Base64` 替代 Apache Commons Codec，避免 Tomcat 依赖冲突。
- 实现了 `VerifyURL` (GET 验证) 和 `DecryptMsg`/`EncryptMsg` (POST 交互)。

Java

```
// 解密示例
WXBizJsonMsgCrypt wxcpt = new WXBizJsonMsgCrypt(sToken, sEncodingAESKey, sCorpID);
String decryptedMsg = wxcpt.DecryptMsg(msgSignature, timestamp, nonce, postData);
```

### 2. 控制器逻辑 (Controller)

核心类：`com.wx.fbsir.business.controller.WechatBotController`

处理 `/api/wechat` 的请求。包含指令清洗逻辑，支持容错匹配。

**指令正则逻辑**：

Java

```
// 匹配 "查看最近 N" (支持中间包含空格)
java.util.regex.Pattern pattern = java.util.regex.Pattern.compile("^查看最近\\s*(\\d+)$");
```

### 3. 业务与持久层 (Service & Mapper)

- **Service**: `InterviewService` 负责参数校验（如限制查询数量最大为 5）和结果格式化。
- **Mapper**: `InterviewMapper` 使用注解式 SQL，包含时间过滤逻辑。

Java

```
// SQL 示例：查询最近记录，排除未来时间
@Select("SELECT * FROM interview_record WHERE interview_time <= NOW() ORDER BY interview_time DESC LIMIT #{limit}")
List<InterviewRecord> selectRecentRecords(int limit);
```

### 2. 隐私脱敏规范

在 `InterviewRecord` 实体类中实现了脱敏逻辑。为了避免 Markdown 渲染冲突（`*` 号会被解析为加粗），统一使用 `x` 作为掩码。

**手机号脱敏**：

Java

```
/**
 * 保留前3后4，中间4位掩盖
 * 例：13800138000 -> 138xxxx8000
 */
private String maskPhoneNumber(String phone) {
    if (phone == null || phone.length() < 11) return phone;
    return phone.replaceAll("(\\d{3})\\d{4}(\\d{4})", "$1xxxx$2");
}
```

**身份证脱敏**：

Java

```
/**
 * 保留前6后4，中间8位掩盖
 * 例：110101199001011234 -> 110101xxxxxxxx1234
 */
private String maskIdCard(String id) {
    if (id == null || id.length() < 15) return id;
    return id.replaceAll("(\\w{6})\\w+(\\w{4})", "$1xxxxxxxx$2");
}
```

## ⚙️ 配置与部署

### 1. 配置文件

在 `application.yml` 或 `application.properties` 中必须配置以下参数：

YAML

```
wechat:
  token: "您的Token"
  aes-key: "您的EncodingAESKey"
  corp-id: "您的企业ID"

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/interview_bot
    username: root
    password: password
```

### 2. 日志规范

项目使用 SLF4J 记录日志，区分日志级别：

- `ERROR`: 异常堆栈（如解密失败、数据库连接错误）。
- `WARN`: 业务警告（如指令格式错误、不支持的消息类型）。
- `INFO`: 关键业务节点（如收到文本指令）。
- `DEBUG`: 调试信息（如原始加密报文、清洗后的指令）。
