## 🏗️ 权限控制体系

### 1. 权限层级

若依框架采用**四级权限体系**：

```
一级菜单（目录）
  └── 二级菜单（页面）
        └── 三级菜单（子页面）
              └── 按钮权限（操作）
```

**权限类型说明：**

| 权限类型 | menu_type | 说明              | 示例 |
|---------|-----------|-----------------|------|
| **目录** | M | 一级菜单，非必要不绑定具体页面 | 内容管理、系统管理 |
| **菜单** | C | 二级/三级菜单，绑定具体页面  | 日更助手、发布记录 |
| **按钮** | F | 按钮级权限，控制页面内操作   | 新增、编辑、删除 |

---

### 2. 菜单ID规划

**统一规划原则：**为便于后续扩展和维护，菜单ID按功能模块分段规划。

| 层级 | ID范围 | 说明 | 示例 |
|------|--------|------|------|
| **一级菜单** | 1-99 | 顶级目录 | 1=内容管理, 2=系统管理 |
| **二级菜单** | 100-499 | 功能页面 | 100=用户管理, 117=日更助手 |
| **三级菜单** | 500-999 | 子页面/子功能 | 500=操作日志, 501=登录日志 |
| **按钮权限** | 1000+ | 按钮级操作 | 1000=用户查询, 1061=文章新增 |

**业务模块ID分配：**

```sql
-- 一级菜单：1-4（系统级）
1    内容管理
2    系统管理
3    系统监控
4    系统工具

-- 二级菜单：100-116（系统级），118+（业务级）
118  日更助手
119  发布记录
...

-- 三级菜单：500+
500  操作日志
501  登录日志
...

-- 按钮权限：1000+
1000-1060  系统按钮
1061-1080  日更助手按钮
1081-1100  发布记录按钮
...
```

**💡 说明：** ID大小不重要，重要的是统一规划、易于梳理和维护。

### 3. 权限标识命名规范

**格式：** `模块:功能:操作`

#### 业务模块权限标识

| 模块 | 前缀 | 示例 |
|------|------|------|
| 日更助手 | business:daily: | business:daily:add |
| 发布记录 | business:publish: | business:publish:list |
| 公众号管理 | business:wechat: | business:wechat:config |
| 系统管理 | system: | system:user:add |
| 监控管理 | monitor: | monitor:online:list |

#### 常用操作后缀

| 操作 | 权限标识 | 说明 |
|------|---------|------|
| **查看** | :view | 进入页面（二级菜单） |
| **列表** | :list | 查询列表数据 |
| **查询** | :query | 查询详情 |
| **新增** | :add | 新增数据 |
| **修改** | :edit | 修改数据 |
| **删除** | :remove | 删除数据 |
| **导出** | :export | 导出数据 |
| **导入** | :import | 导入数据 |
| **配置** | :config | 配置设置 |
| **排版** | :layout | 智能排版 |
| **发布** | :publish | 发布到公众号 |

**示例：**

```sql
-- 日更助手权限标识
business:daily:view      -- 查看页面（二级菜单）
business:daily:query     -- 查询文章列表
business:daily:add       -- 新增文章
business:daily:remove    -- 删除文章
business:daily:config    -- 智能体配置
business:daily:layout    -- 智能排版
business:daily:publish   -- 发布公众号

-- 发布记录权限标识
business:publish:list    -- 查看页面（二级菜单）
business:publish:query   -- 查询记录详情
business:publish:remove  -- 删除记录
```

**操作列权限控制：**

### 1. Controller 注解

使用 `@PreAuthorize` 注解控制接口权限：

```java
@RestController
@RequestMapping("/business/daily-article")
public class DailyArticleController extends BaseController {
    
    /**
     * 查询文章列表
     */
    @PreAuthorize("@ss.hasPermi('business:daily:query')")
    @GetMapping("/list")
    public TableDataInfo list(DailyArticle dailyArticle) {
        startPage();
        List<DailyArticle> list = dailyArticleService.selectDailyArticleList(dailyArticle);
        return getDataTable(list);
    }
    
    /**
     * 新增文章
     */
    @PreAuthorize("@ss.hasPermi('business:daily:add')")
    @PostMapping
    public AjaxResult add(@Validated @RequestBody DailyArticle dailyArticle) {
        dailyArticle.setUserId(getUserId());
        return toAjax(dailyArticleService.insertDailyArticle(dailyArticle));
    }
    
    /**
     * 修改文章
     */
    @PreAuthorize("@ss.hasPermi('business:daily:edit')")
    @PutMapping
    public AjaxResult edit(@Validated @RequestBody DailyArticle dailyArticle) {
        return toAjax(dailyArticleService.updateDailyArticle(dailyArticle));
    }
    
    /**
     * 删除文章
     */
    @PreAuthorize("@ss.hasPermi('business:daily:remove')")
    @DeleteMapping("/{ids}")
    public AjaxResult remove(@PathVariable Long[] ids) {
        return toAjax(dailyArticleService.deleteDailyArticleByIds(ids));
    }
    
    /**
     * 智能体配置
     */
    @PreAuthorize("@ss.hasPermi('business:daily:config')")
    @GetMapping("/config")
    public AjaxResult getConfig() {
        // ...
    }
    
    /**
     * 智能排版
     */
    @PreAuthorize("@ss.hasPermi('business:daily:layout')")
    @PostMapping("/layout")
    public AjaxResult layout(@RequestBody Map<String, String> params) {
        // ...
    }
    
    /**
     * 发布到公众号
     */
    @PreAuthorize("@ss.hasPermi('business:daily:publish')")
    @PostMapping("/publish")
    public AjaxResult publish(@RequestBody Map<String, Object> params) {
        // ...
    }
}
```

### 2. 数据权限

所有业务数据必须绑定用户ID，确保数据隔离：

```java
@Service
public class DailyArticleServiceImpl implements IDailyArticleService {
    
    @Autowired
    private DailyArticleMapper dailyArticleMapper;
    
    /**
     * 查询文章列表（自动过滤当前用户数据）
     */
    @Override
    public List<DailyArticle> selectDailyArticleList(DailyArticle dailyArticle) {
        // ✅ 正确：自动注入当前用户ID，确保数据隔离
        Long userId = SecurityUtils.getUserId();
        dailyArticle.setUserId(userId);
        return dailyArticleMapper.selectDailyArticleList(dailyArticle);
    }
    
    /**
     * 删除文章
     */
    @Override
    public int deleteDailyArticleByIds(Long[] ids) {
        Long userId = SecurityUtils.getUserId();
        
        // ✅ 正确：删除前验证数据所有权
        for (Long id : ids) {
            DailyArticle article = dailyArticleMapper.selectDailyArticleById(id);
            if (article == null || !article.getUserId().equals(userId)) {
                throw new ServiceException("无权删除该文章");
            }
        }
        
        return dailyArticleMapper.deleteDailyArticleByIds(ids);
    }
}
```

**❌ 错误示例：**

```java
// ❌ 错误：不验证数据所有权，用户可以删除他人数据
@Override
public int deleteDailyArticleByIds(Long[] ids) {
    return dailyArticleMapper.deleteDailyArticleByIds(ids);
}

// ❌ 错误：不过滤用户数据，可以查询他人数据
@Override
public List<DailyArticle> selectDailyArticleList(DailyArticle dailyArticle) {
    return dailyArticleMapper.selectDailyArticleList(dailyArticle);
}
```

#### 后端Controller示例

**文件路径：** `FBSir-admin/src/main/java/com/wx/fbsir/web/controller/system/SysUserController.java`

```java
@RestController
@RequestMapping("/system/user")
public class SysUserController extends BaseController {
    
    @Autowired
    private ISysUserService userService;
    
    /**
     * 获取用户列表
     * 权限标识：system:user:list
     */
    @PreAuthorize("@ss.hasPermi('system:user:list')")
    @GetMapping("/list")
    public TableDataInfo list(SysUser user) {
        startPage();
        List<SysUser> list = userService.selectUserList(user);
        return getDataTable(list);
    }
    
    /**
     * 根据用户ID获取详细信息
     * 权限标识：system:user:query
     */
    @PreAuthorize("@ss.hasPermi('system:user:query')")
    @GetMapping(value = {"/{userId}"})
    public AjaxResult getInfo(@PathVariable Long userId) {
        userService.checkUserDataScope(userId);
        SysUser sysUser = userService.selectUserById(userId);
        AjaxResult ajax = AjaxResult.success();
        ajax.put(AjaxResult.DATA_TAG, sysUser);
        return ajax;
    }
    
    /**
     * 新增用户
     * 权限标识：system:user:add
     */
    @PreAuthorize("@ss.hasPermi('system:user:add')")
    @Log(title = "用户管理", businessType = BusinessType.INSERT)
    @PostMapping
    public AjaxResult add(@Validated @RequestBody SysUser user) {
        if (!userService.checkUserNameUnique(user)) {
            return error("新增用户'" + user.getUserName() + "'失败，登录账号已存在");
        }
        user.setCreateBy(getUsername());
        user.setPassword(SecurityUtils.encryptPassword(user.getPassword()));
        return toAjax(userService.insertUser(user));
    }
    
    /**
     * 修改用户
     * 权限标识：system:user:edit
     */
    @PreAuthorize("@ss.hasPermi('system:user:edit')")
    @Log(title = "用户管理", businessType = BusinessType.UPDATE)
    @PutMapping
    public AjaxResult edit(@Validated @RequestBody SysUser user) {
        userService.checkUserAllowed(user);
        userService.checkUserDataScope(user.getUserId());
        user.setUpdateBy(getUsername());
        return toAjax(userService.updateUser(user));
    }
    
    /**
     * 删除用户
     * 权限标识：system:user:remove
     */
    @PreAuthorize("@ss.hasPermi('system:user:remove')")
    @Log(title = "用户管理", businessType = BusinessType.DELETE)
    @DeleteMapping("/{userIds}")
    public AjaxResult remove(@PathVariable Long[] userIds) {
        if (ArrayUtils.contains(userIds, getUserId())) {
            return error("当前用户不能删除");
        }
        return toAjax(userService.deleteUserByIds(userIds));
    }
    
    /**
     * 导出用户数据
     * 权限标识：system:user:export
     */
    @Log(title = "用户管理", businessType = BusinessType.EXPORT)
    @PreAuthorize("@ss.hasPermi('system:user:export')")
    @PostMapping("/export")
    public void export(HttpServletResponse response, SysUser user) {
        List<SysUser> list = userService.selectUserList(user);
        ExcelUtil<SysUser> util = new ExcelUtil<SysUser>(SysUser.class);
        util.exportExcel(response, list, "用户数据");
    }
    
    /**
     * 导入用户数据
     * 权限标识：system:user:import
     */
    @Log(title = "用户管理", businessType = BusinessType.IMPORT)
    @PreAuthorize("@ss.hasPermi('system:user:import')")
    @PostMapping("/importData")
    public AjaxResult importData(MultipartFile file, boolean updateSupport) throws Exception {
        ExcelUtil<SysUser> util = new ExcelUtil<SysUser>(SysUser.class);
        List<SysUser> userList = util.importExcel(file.getInputStream());
        String message = userService.importUser(userList, updateSupport, getUsername());
        return success(message);
    }
    
    /**
     * 重置密码
     * 权限标识：system:user:resetPwd
     */
    @PreAuthorize("@ss.hasPermi('system:user:resetPwd')")
    @Log(title = "用户管理", businessType = BusinessType.UPDATE)
    @PutMapping("/resetPwd")
    public AjaxResult resetPwd(@RequestBody SysUser user) {
        userService.checkUserAllowed(user);
        userService.checkUserDataScope(user.getUserId());
        user.setPassword(SecurityUtils.encryptPassword(user.getPassword()));
        user.setUpdateBy(getUsername());
        return toAjax(userService.resetPwd(user));
    }
}
```

**关键点说明：**
1. ✅ **权限注解：** 每个接口都使用 `@PreAuthorize("@ss.hasPermi('权限标识')")`
2. ✅ **日志注解：** 重要操作使用 `@Log` 注解记录日志
3. ✅ **数据校验：** 使用 `@Validated` 验证请求参数
4. ✅ **数据权限：** 调用 `checkUserDataScope` 确保用户只能操作自己有权限的数据
