## 1. 背景与问题

13 个 OpenSpec 阶段的知识散落在归档目录、spec 文件、代码注释中。对外发布需要一份结构化的产品文档，让第三方开发者能自助接入。

**关键要求**：项目部署在 `api.U3W.com` 域名下，文档中所有 API 示例必须使用此域名。

---

## 2. 目标

基于已归档的 #1-#13、#15，以及现有实现/阶段规划中的 #14 能力，生成 SDK 级产品文档。

## 6. 文档规范

| 维度 | 要求 |
|------|------|
| **域名** | 所有 API 示例使用 `https://api.U3W.com`（注意大小写） |
| **语言** | 中文为主，API 路径/参数名用英文 |
| **格式** | Markdown → 可部署为静态站点（如 VuePress/Docusaurus） |
| **版本** | 对齐 spec v1.8 + Skill v2.1.2 |
| **代码示例** | cURL + Python + Node.js 三语言 |
